# 4.1 儿童常见病症与安全用药——孩子不是缩小版的成人

> 儿童的生理特点决定了他们在用药上与成人有着本质区别——肝脏代谢能力不成熟、肾脏排泄能力弱、血脑屏障发育不全。很多对成人安全的药，对儿童可能是禁忌甚至毒药。

## 一、儿童用药的核心原则

### 1.1 剂量：按体重，不按年龄

儿童用药剂量**首选按体重计算**，年龄只是辅助。

```
剂量(mg) = 体重(kg) × 每公斤体重剂量(mg/kg)
服用体积(ml) = 剂量(mg) ÷ 药液浓度(mg/ml)
```

**实操示例**：一名15kg的3岁儿童发热，需要用布洛芬（浓度20mg/ml）

> 布洛芬儿童剂量：5-10mg/kg/次
> 15kg × 5mg = 75mg（最小剂量）
> 15kg × 10mg = 150mg（最大剂量）
> 服用体积 = 75÷20 = **3.75ml** 至 150÷20 = **7.5ml**

### 1.2 儿童用药五条铁律

| 铁律 | 说明 |
|------|------|
| ① 用儿童剂型 | 混悬液/滴剂/颗粒剂，不要掰成人药片 |
| ② 用量杯/滴管 | 绝不用汤匙"大概倒"，剂量误差可能导致中毒或无效 |
| ③ 记录用药 | 记下每次用药的时间、剂量，避免家人重复给药 |
| ④ 不混用 | 不要多种药一起吃或混在奶/果汁里 |
| ⑤ 放高处 | 所有药品锁在孩子拿不到的地方 |

## 二、儿童绝对禁用的药物

> 🔴 这些药在儿童使用中已有明确的安全风险，家庭药箱里绝对不要出现。

| 药物 | 禁用的原因 |
|------|-----------|
| **阿司匹林** | 12岁以下禁用——可引起瑞氏综合征（Reye Syndrome），脑+肝损伤，死亡率高 |
| **洛哌丁胺（易蒙停）** | 12岁以下禁用——可能引起麻痹性肠梗阻 |
| **安乃近** | 已退市——可致粒细胞缺乏症 |
| **尼美舒利** | 12岁以下禁用——肝损伤风险 |
| **氨基糖苷类抗生素**（庆大霉素/阿米卡星） | 有耳毒性、肾毒性 |
| **喹诺酮类**（左氧氟沙星/诺氟沙星） | 18岁以下禁用——影响软骨发育 |
| **四环素类** | 8岁以下禁用——影响牙齿和骨骼发育 |

## 三、儿童常见病症的专项处理

### 3.1 儿童发热

| 年龄 | 处理要点 |
|------|---------|
| **<3个月** | **任何发热都要立即就医**，不要在家处理 |
| 3-6个月 | 首选对乙酰氨基酚（按体重算剂量） |
| >6个月 | 对乙酰氨基酚或布洛芬均可 |

> ⚠️ **婴儿发热的特殊性**：小婴儿免疫系统不成熟，发热可能是不典型感染（如尿路感染、脑膜炎）的唯一表现。"才低烧没事"这种想法在婴儿身上可能致命。

**儿童退热药物速查**：

| 药品 | 单次剂量 | 最小间隔 | 每日最多 | 剂型 |
|------|---------|---------|---------|------|
| 对乙酰氨基酚 | 10-15mg/kg | 4小时 | 4次 | 滴剂/混悬液/栓剂 |
| 布洛芬 | 5-10mg/kg | 6小时 | 4次 | 混悬液/栓剂 |

### 3.2 儿童感冒

- **6岁以下不建议使用复方感冒药**——证据不足且副作用风险大
- 鼻塞：生理盐水喷鼻/洗鼻 + 吸鼻器
- 咳嗽：>1岁可用蜂蜜（每次2-5ml），>2岁可考虑单一成分祛痰药
- 多数儿童感冒7-10天自愈，不需要用药

### 3.3 儿童腹泻

| 操作 | 说明 |
|------|------|
| **口服补液盐** | 最核心的治疗——每次稀便后补充（<2岁：50-100ml；>2岁：100-200ml） |
| 继续喂养 | 母乳继续、配方奶不需稀释 |
| 蒙脱石散 | 可用，安全 |
| 补锌 | 可缩短病程（10-20mg/日，10-14天） |
| 益生菌 | 辅助，证据有限但安全 |

> 🔴 **脱水是儿童腹泻最主要的危险**。识别脱水：精神萎靡、眼窝凹陷、口干、皮肤弹性差、尿少（6小时无尿）→ 立即就医。

## 四、儿童常见意外预防

| 风险 | 预防措施 |
|------|---------|
| 误服药物 | 所有药上锁，不放在床头柜/茶几 |
| 误服成人药 | 尤其危险：降压药、降糖药、安眠药——一粒可致命 |
| 滴鼻剂过量 | 儿童只用儿童浓度的滴鼻剂 |
| 退烧药过量 | 记录每次用药，家庭内部做好沟通（父母/老人之间） |

> 🔴 如果孩子误服成人药物，**立即带上药瓶去医院急诊**，不要自行催吐。

## 五、本章小结

儿童用药的核心是：按体重算剂量、用儿童剂型、绝不用成人药代替。阿司匹林、洛哌丁胺、安乃近等药物对儿童绝对禁用。婴儿发热必须尽早就医。感冒通常不需要用药，腹泻最重要的是口服补液。家中有儿童时，药品必须上锁存放——一颗成人降压药可能让幼儿丧命。下一章将讨论老年人用药的注意事项。
