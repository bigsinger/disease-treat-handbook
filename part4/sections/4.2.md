# 4.2 老年人用药注意事项——药越多，风险越大

> 老年人往往同时患有多种慢性病，每天服用多种药物。药物之间的相互作用、肝肾功能减退导致的代谢变慢、以及身体对药物反应的改变，使得老年人是用药风险最高的人群。

## 一、老年人生理变化如何影响用药

### 1.1 四大变化

| 生理变化 | 对用药的影响 |
|---------|-------------|
| **肝功能减退** | 药物代谢变慢，血药浓度升高 |
| **肾功能减退** | 药物排泄变慢，易蓄积中毒 |
| **体脂增加/肌肉减少** | 脂溶性药物分布改变，作用时间延长 |
| **受体敏感性改变** | 对某些药物（如镇静药、降压药）更敏感 |

> 🔑 同样是"一片"药，30岁和70岁的身体处理速度可能相差一倍以上。

### 1.2 老年人用药的通用剂量原则

- 起始剂量：成人剂量的 **1/2~2/3**
- 缓慢加量，观察反应
- 肝肾功能明显减退者需进一步减量
- 对于主要经肾脏排泄的药物（如某些抗生素、二甲双胍），需根据肾功能调整

## 二、多重用药——老年人的最大用药风险

### 2.1 什么是多重用药？

同时使用≥5种药物即为多重用药。许多老人同时服用降压药、降糖药、降脂药、抗血小板药、钙片等，再加上临时使用的感冒药、止痛药——药越多，相互作用越复杂。

### 2.2 最危险的药物组合

| 危险组合 | 风险 |
|---------|------|
| 华法林 + 阿司匹林/布洛芬 | **严重出血**——消化道出血、脑出血 |
| 华法林 + 某些抗生素 | 国际标准化比值（INR）飙升，出血风险剧增 |
| 降压药 + 布洛芬 | 布洛芬削弱降压效果，血压可能失控 |
| ACEI/ARB类降压药 + 保钾利尿剂 | 高钾血症——致命性心律失常 |
| 多种镇静/安眠药叠加 | 过度镇静、跌倒、呼吸抑制 |

### 2.3 老年人药物管理清单

建议为家中老人建立一张"用药清单"，包含以下信息：

| 项目 | 示例 |
|------|------|
| 药品名 | 硝苯地平控释片（拜新同） |
| 用途 | 降血压 |
| 用法用量 | 每日1次，每次30mg，早晨空腹 |
| 开始日期 | 2025年3月 |
| 开药医生/科室 | 心内科 张医生 |
| 注意事项 | 不可掰开服用；与葡萄柚汁间隔4小时 |

> 这张清单每次看病时带给医生——这是防止重复开药、药药冲突的最有效手段。

## 三、老年人高风险药物速查

### 3.1 容易引起跌倒的药物

跌倒是老年人意外死亡的首要原因，以下药物会明显增加跌倒风险：

| 药物类别 | 常见药品 | 风险机制 |
|---------|---------|---------|
| 安眠镇静药 | 艾司唑仑、阿普唑仑、唑吡坦 | 嗜睡、头晕、肌力下降 |
| 降压药 | 各类降压药 | 体位性低血压——起身时头晕眼前发黑 |
| 降糖药 | 胰岛素、磺脲类 | 低血糖导致晕厥 |
| 抗组胺药（一代） | 氯苯那敏（扑尔敏） | 嗜睡 |
| 利尿剂 | 呋塞米、氢氯噻嗪 | 频繁上厕所增加跌倒机会 |

### 3.2 老年人应慎重使用的非处方药

| 药物 | 原因 |
|------|------|
| 布洛芬等NSAIDs | 肾损伤、胃出血风险高于年轻人 |
| 含伪麻黄碱的感冒药 | 升高血压、心率加快 |
| 一代抗组胺药（扑尔敏） | 嗜睡、认知功能下降、尿潴留 |
| 含可待因的止咳药 | 呼吸抑制风险 |
| 泻药（刺激性） | 长期使用电解质紊乱 |

> 🔑 老年人退热镇痛首选**对乙酰氨基酚**（肝功能正常者），次选布洛芬（短期、饭后）。

## 四、常见慢性病老人的用药特别提醒

### 4.1 高血压老人

- 感冒药别乱吃：含伪麻黄碱的感冒药会升高血压
- 布洛芬可能削弱降压药效果，需要止痛时首选对乙酰氨基酚
- 降压药不要因为"血压正常了"就自行停药

### 4.2 糖尿病老人

- 感冒/感染期间血糖可能波动，需加强监测
- 糖浆类感冒药含糖，选无糖剂型
- 某些退烧药可能影响血糖（布洛芬增强磺脲类降糖效果）

### 4.3 服用抗凝药（华法林）的老人

- **不要自行添加任何新药**——很多OTC药和保健品（如银杏叶、维生素E、鱼油）都会影响INR
- 感冒、感染本身也会影响INR
- 用任何新药前咨询医生

## 五、服药管理实用工具

| 方法 | 说明 |
|------|------|
| **一周药盒** | 按早/中/晚/睡前分格，避免漏服或重复服用 |
| **用药清单卡** | 随身携带，含药物名称、剂量、过敏史 |
| **定时提醒** | 手机闹钟或智能药盒 |
| **定期复核** | 每3-6个月请医生/药师复核所有用药，停用不再需要的药 |

## 六、本章小结

老年人用药的核心风险是"多重用药"——药越多，相互作用越复杂。起始剂量应从成人半量开始，特别注意布洛芬类止痛药的肾损伤和胃出血风险、感冒药对血压的影响。建立用药清单、使用一周药盒、定期请医生复核所有药物——这些简单措施可以显著降低老年人的用药风险。下一章将讨论孕期和哺乳期的用药安全。
