# 3.1 皮肤过敏与炎症——痒比痛更难忍

> 皮肤是人体最大的器官，也是最容易"闹脾气"的器官。荨麻疹、湿疹、接触性皮炎是最常见的三种皮肤问题，虽然恼人，但大多数可以在家用对药控制。

## 一、荨麻疹——来去如风的"风团"

### 1.1 识别特征

- 皮肤突然出现红色或肤色**风团**（隆起的斑块）
- **剧烈瘙痒**
- 单个风团通常在24小时内消退，但新疹不断出现
- 按压中心可变白
- 严重时可伴嘴唇、眼睑肿胀（血管性水肿）

### 1.2 常见诱因

| 类别 | 常见诱因 |
|------|---------|
| 食物 | 海鲜、鸡蛋、坚果、芒果 |
| 药物 | 抗生素（尤其青霉素类）、阿司匹林 |
| 感染 | 病毒/细菌感染（感冒后常见） |
| 物理因素 | 冷、热、日晒、压力、摩擦 |
| 不明原因 | 约50%的急性荨麻疹找不到确切诱因 |

### 1.3 家庭处理

**第一步：口服抗组胺药——核心治疗**

| 药物 | 特点 | 用法 |
|------|------|------|
| 西替利嗪（仙特明）| 起效快，效果强 | 成人10mg/日，儿童按年龄调整 |
| 氯雷他定（开瑞坦）| 无嗜睡，适合白天 | 成人10mg/日 |
| 依巴斯汀 | 长效，无嗜睡 | 成人10-20mg/日 |

> 🔑 荨麻疹的抗组胺药需要**规律服用**直到皮疹完全消退后2-3天，而不是"起了才吃、退了就停"。一般疗程7-14天。

**第二步：外用止痒**

- 炉甘石洗剂：涂抹于风团处，止痒快
- 避免搔抓，冷敷可缓解瘙痒

### 1.4 荨麻疹的紧急情况

出现以下任一情况，**立即去急诊**：
- 嘴唇、眼睑、舌头肿胀
- 喉咙发紧、声音嘶哑
- 呼吸困难、喘息
- 头晕、意识模糊——这是**过敏性休克**的征兆，可致命！

## 二、湿疹——不只是"皮肤干"

### 2.1 识别特征

- 皮肤干燥、粗糙、脱屑
- **剧烈瘙痒**，越抓越痒
- 红斑、丘疹，严重时渗液、结痂
- 好发部位：肘窝、腘窝（膝盖后）、面部、手部
- 慢性反复发作，时好时坏

### 2.2 湿疹治疗的两大支柱

**保湿 + 激素药膏**，二者缺一不可。

**第一支柱：保湿——日常基础**

| 保湿要点 | 说明 |
|---------|------|
| 频率 | 每天至少2次，洗澡后3分钟内立即涂抹 |
| 产品选择 | 无香料、无色素、成分简单的保湿霜（凡士林、丝塔芙、适乐肤等） |
| 用量 | 要"舍得用"——全身涂抹，不是"抹一点" |

**第二支柱：外用激素——控制炎症**

| 激素强度 | 代表药物 | 使用部位 | 使用时间 |
|---------|---------|---------|---------|
| 弱效 | 氢化可的松（尤卓尔）| 面部、颈部、腋下 | 短期，遵医嘱 |
| 中效 | 糠酸莫米松（艾洛松）| 躯干、四肢 | ≤2周 |
| 强效 | 倍他米松 | 手掌、脚底等厚皮肤 | 短期、遵医嘱 |

> ⚠️ **"激素恐惧"是湿疹治疗的最大障碍**。短期（1-2周）规范使用外用激素是安全有效的，长期不控制的湿疹对生活质量的损害远大于外用激素的风险。

### 2.3 湿疹加重的常见原因

- **停用保湿** → 皮肤屏障持续受损 → 湿疹复发
- 洗澡水太热、时间太长、用碱性肥皂
- 紧张、焦虑、压力
- 接触过敏原（尘螨、花粉、宠物毛屑）

## 三、接触性皮炎——"碰到了不该碰的东西"

### 3.1 两种类型

| 类型 | 机制 | 举例 |
|------|------|------|
| **刺激性接触性皮炎** | 皮肤直接受损 | 强酸、强碱、洗涤剂、频繁洗手 |
| **变应性接触性皮炎** | 迟发型过敏反应 | 染发剂、金属（镍）、化妆品、乳胶 |

### 3.2 处理方案

| 步骤 | 操作 |
|------|------|
| 1. 脱离 | 立即脱离接触物，大量清水冲洗15分钟 |
| 2. 止痒 | 口服西替利嗪/氯雷他定 + 外用炉甘石洗剂 |
| 3. 抗炎 | 轻中度：弱中效外用激素5-7天 |
| 4. 保护 | 保湿修复皮肤屏障 |

## 四、几条皮肤护理铁律

1. **痒的时候不要抓**——搔抓破坏皮肤屏障，越抓越痒，形成恶性循环。改冷敷或拍打
2. **激素药膏见好就收**——皮疹消退后改为保湿维持，不要长期依赖外用激素
3. **抗生素软膏别滥用**——皮肤红肿不等于细菌感染，湿疹不需要抗生素软膏
4. **过敏体质的人**——皮肤问题的背后常常有一个过敏体质的"底子"

## 五、何时需要看皮肤科医生？

- 皮疹面积大、进展快
- 自我用药1周无效
- 出现水疱、脓疱、糜烂、渗液
- 伴有发热
- 皮疹影响面部、生殖器区域
- 反复发作影响生活质量

## 六、本章小结

荨麻疹用口服抗组胺药规律治疗，出现呼吸道症状立即急诊。湿疹靠"保湿+激素"双支柱管理，不必恐惧短期外用激素。接触性皮炎首先要脱离接触源。皮肤问题的核心逻辑是——先止痒防抓，再抗炎消疹，最后修复屏障。下一章将讨论家庭常见的擦伤、烫伤和扭伤处理。
