# 3.3 五官科与口腔问题——眼耳鼻口，小毛病大学问

> 眼睛红、耳朵痛、鼻子堵、口腔溃疡——这些"小毛病"虽然不致命，却严重影响生活质量。五官科问题很多时候不需要去医院，但需要正确的判断和处理。

## 一、眼部常见问题

### 1.1 结膜炎（红眼病）

| 类型 | 特征 | 处理 |
|------|------|------|
| **病毒性** | 水样分泌物、耳前淋巴结肿大、常伴感冒 | 自限性，冷敷缓解，一般1-2周自愈 |
| **细菌性** | **脓性分泌物**（黄绿色）、晨起眼皮黏住 | 抗生素滴眼液（左氧氟沙星/妥布霉素） |
| **过敏性** | **奇痒**、眼红、流泪、常伴鼻炎 | 抗过敏滴眼液（奥洛他定/酮替芬） |

**家庭处理要点**：

| 操作 | 说明 |
|------|------|
| 冷敷 | 缓解不适，每次5-10分钟 |
| 清洁 | 用干净湿棉球从内眼角向外擦，每只眼用新棉球 |
| 不揉眼 | 揉眼会加重炎症和传染 |
| 隔离 | 病毒性和细菌性结膜炎有传染性，毛巾、枕巾分开 |

### 1.2 麦粒肿（针眼）

- 眼皮边缘出现红肿、疼痛的小硬结
- 是睫毛毛囊或睑板腺的细菌感染

**处理方案**：
1. **热敷**——核心治疗：用温热毛巾敷患处，每次10-15分钟，每天3-4次。热敷可促进脓点"冒头"自行排出
2. 外用抗生素眼膏（妥布霉素/左氧氟沙星眼膏）涂于眼睑缘
3. 可能需要口服抗生素（如果红肿范围扩大）
4. **千万不要挤！**——面部"危险三角区"的感染挤压可能引发颅内感染

> ⚠️ 麦粒肿超过1周不消退或反复发作，需看眼科。

## 二、耳部常见问题

### 2.1 外耳道炎（游泳耳）

- 耳道瘙痒、疼痛，牵拉耳廓时疼痛加剧
- 常见于游泳后、频繁掏耳朵后

| 处理 | 说明 |
|------|------|
| 保持干燥 | 洗澡游泳时用棉球蘸凡士林塞住耳道口 |
| 抗生素滴耳液 | 氧氟沙星滴耳液，每天2-3次 |
| 止痛 | 布洛芬可用于止痛 |
| 不要掏耳 | 暂停使用棉签/挖耳勺 |

### 2.2 急性中耳炎

- 耳深部疼痛、可能伴发热、听力下降
- **儿童高发**（咽鼓管短平）

| 处理 | 说明 |
|------|------|
| 止痛 | 对乙酰氨基酚或布洛芬 |
| 观察 | 2岁以上轻症可观察48小时，很多病毒性中耳炎自愈 |
| 抗生素 | 只有确诊细菌性中耳炎才需要（需医生判断） |
| 就医指征 | 持续高热、耳痛剧烈、耳流脓、<6月龄婴儿 |

### 2.3 耵聍栓塞（耳屎堵住）

- 听力突然下降、耳闷、耳鸣
- 不要用棉签（越推越深）
- 碳酸氢钠滴耳液浸泡软化后，去医院耳鼻喉科冲洗
- 不要自己在家用任何工具掏

## 三、鼻部常见问题

### 3.1 过敏性鼻炎

| 症状 | 阵发性打喷嚏、流清涕、鼻塞、鼻痒 |
|------|----------------------------------|

**阶梯治疗**：

| 阶梯 | 方案 | 说明 |
|------|------|------|
| 第一阶梯 ⭐ | 鼻用糖皮质激素喷雾（糠酸莫米松/氟替卡松） | **一线治疗**，需持续使用，至少2周起效 |
| 第二阶梯 | 口服抗组胺药（西替利嗪/氯雷他定） | 辅助，快速缓解急性症状 |
| 辅助 | 生理盐水洗鼻 | 冲洗过敏原和分泌物 |

> 🔑 **关键认知**：过敏性鼻炎的治疗核心是**控制炎症**，不是"止住喷嚏"。鼻用激素喷雾是长期管理的基础，它不是"激素依赖"，而是控制鼻炎需要持续用药。

### 3.2 鼻出血（流鼻血）

**正确处理**：
1. 身体前倾（**不要后仰**——血液倒流可能呛入气管或吞入胃中引起呕吐）
2. 用拇指和食指**捏住鼻翼**（软骨部分），持续压迫10-15分钟
3. 期间用嘴呼吸，不要松开看"止住了没"
4. 冷敷鼻梁或前额辅助收缩血管

**如果出现以下情况，去急诊**：
- 压迫15分钟后仍出血不止
- 出血量大、从口腔涌出
- 伴有头晕、面色苍白
- 正在服用抗凝药物（华法林、阿司匹林等）

## 四、口腔与咽喉常见问题

### 4.1 口腔溃疡（口疮）

- 圆形或椭圆形，中央凹陷、周围红晕、剧痛
- 通常7-14天自愈

| 处理 | 说明 |
|------|------|
| 止痛 | 利多卡因凝胶局部涂抹（饭前用） |
| 促进愈合 | 西地碘含片（华素片）、复方氯己定含漱液 |
| 保护 | 口腔溃疡贴膜覆盖溃疡面，减少刺激 |
| 营养 | 补充维生素B族，避免辛辣刺激食物 |

> ⚠️ 超过2周不愈合的口腔溃疡、位置固定反复发作、质地硬、边界不规则——**必须就医排除口腔癌**。

### 4.2 咽喉炎

| 类型 | 特征 | 处理 |
|------|------|------|
| 病毒性（占90%） | 咽痛+感冒症状 | 含片+温水漱口+休息，无需抗生素 |
| 细菌性（链球菌） | **剧烈咽痛、高热、扁桃体有白色脓点**、无咳嗽 | 需就医，可能需要抗生素 |

- 盐水漱口（温水+半勺盐）可缓解
- 西地碘含片/西瓜霜含片
- 多喝温水，保持喉咙湿润

## 五、本章小结

眼部问题要分清水样分泌物（病毒）还是脓性分泌物（细菌），麦粒肿热敷不挤压。中耳炎儿童高发，先止痛观察。过敏性鼻炎用鼻喷激素长期管理。鼻出血身体前倾捏鼻翼，不要后仰。口腔溃疡多在2周内自愈，超过2周不愈合要警惕。绝大多数五官科问题可以通过正确的家庭处理得到控制，关键在于正确识别和及时干预。
