# 5.2 蛇虫叮咬与野外创伤——远离医院时的生命防线

> 蛇咬、蜂蜇、蜱虫、蚂蟥——这些是户外活动者最担心的意外。处理原则各不相同，用错方法可能比咬伤本身更危险。

## 一、毒蛇咬伤——争分夺秒的正确处理

### 1.1 毒蛇 vs 无毒蛇咬伤的快速识别

| 特征 | 毒蛇咬伤 | 无毒蛇咬伤 |
|------|---------|-----------|
| 牙痕 | **1-2个深大牙痕**（毒牙孔） | 多排细小牙痕 |
| 疼痛 | **剧烈灼痛**，迅速加重 | 轻微刺痛 |
| 肿胀 | **快速肿胀**，向近端蔓延 | 不明显 |
| 全身症状 | 恶心、呕吐、视物模糊、呼吸困难 | 无 |

> ⚠️ 如果不能确定是否毒蛇，**一律按毒蛇咬伤处理**。

### 1.2 毒蛇咬伤急救——"静、低、固、送"

| 步骤 | 操作 | 说明 |
|------|------|------|
| **① 静** | 保持冷静，**绝对不动** | 活动加速毒液扩散，让伤者平卧或半卧 |
| **② 低** | 咬伤部位**低于心脏** | 减缓毒液向心脏回流 |
| **③ 固** | **压力固定法**：用弹性绷带从远端向近端包扎整个被咬肢体 | 松紧度以能伸入一指为宜，不要阻断动脉血流 |
| **④ 送** | 立即呼叫120或用最快方式送医 | 带上死蛇（拍照也行，便于识别用何种抗蛇毒血清） |

### 1.3 毒蛇咬伤的绝对禁忌

| 错误做法 | 为什么致命 |
|---------|-----------|
| ❌ **用嘴吸毒** | 施救者口腔黏膜可吸收毒液；如果口腔有溃疡/伤口，等于两人都中毒 |
| ❌ 切开伤口排毒 | 加重组织损伤+感染风险，排毒效果极差 |
| ❌ 冰敷 | 加重局部组织坏死（中国毒蛇以血循毒为主） |
| ❌ 喝酒"止痛" | 加速毒液吸收 |
| ❌ 追打毒蛇 | 浪费时间+可能二次被咬；拍照即可 |
| ❌ 跑步去求救 | 加速毒液扩散——打电话，让人来抬你 |

### 1.4 关于"蛇药片"

- 季德胜蛇药片等中成药有一定辅助作用，可口服+外敷
- 但**绝对不能替代去医院注射抗蛇毒血清**
- 只能在去医院途中作为辅助使用

## 二、蜂蜇——一只和一群是完全不同的概念

### 2.1 单只蜂蜇

| 步骤 | 操作 |
|------|------|
| ① | 用钝器（指甲、银行卡边缘）**刮除**毒刺——不要用镊子夹（会挤出更多毒液） |
| ② | 肥皂水清洗伤口 |
| ③ | 冰敷减轻肿痛（每次15-20分钟） |
| ④ | 口服西替利嗪/氯雷他定止痒 |
| ⑤ | 布洛芬止痛 |

> 🔑 蜂蜇后的疼痛和肿胀是**局部反应**，不是"中毒"。除非过敏，否则不会危及生命。

### 2.2 群蜂蜇伤（>10处）

- 属于医疗急症，需要尽快就医
- 大量蜂毒可导致横纹肌溶解、急性肾损伤
- 去医院途中可以口服抗组胺药

### 2.3 蜂蜇过敏——致命风险

如果被蜇后出现以下症状，是**过敏性休克**——立即注射肾上腺素（如有）+ 呼叫急救：

- 全身荨麻疹（不限于蜇伤部位）
- 嘴唇/眼睑/舌头肿胀
- 呼吸困难、喉咙发紧
- 头晕、意识模糊

> 有过蜂蜇严重过敏史的人，户外应随身携带**肾上腺素自动注射笔**（EpiPen）。

## 三、蜱虫叮咬——千万别硬拔！

### 3.1 蜱虫为什么危险？

蜱虫可能携带多种病原体，包括莱姆病螺旋体、森林脑炎病毒、发热伴血小板减少综合征病毒（新型布尼亚病毒）等。

### 3.2 正确取出方法

| 步骤 | 操作 |
|------|------|
| ① | 用**尖头镊子**尽可能贴近皮肤夹住蜱虫的**头部**（不是身体） |
| ② | **垂直、稳定、缓慢**地向上拔出，不要扭转或猛拉 |
| ③ | 确保口器完整取出——如果口器残留，用消毒针挑出 |
| ④ | 碘伏消毒伤口 |
| ⑤ | 用透明胶带粘住蜱虫或用酒精泡死后密封丢弃 |

### 3.3 取出蜱虫的禁忌

| 错误做法 | 为什么错 |
|---------|---------|
| ❌ 手指硬拔/猛扯 | 头部断在皮肤里，且挤压身体可能将更多病原注入 |
| ❌ 涂酒精/指甲油/凡士林 | "窒息"蜱虫让它自己松口——**它可能在窒息前吐出一肚子病原体** |
| ❌ 用打火机/烟头烫 | 烫伤自己+蜱虫应激反吐 |

### 3.4 蜱虫叮咬后的观察

叮咬后4周内注意：
- 叮咬处出现**牛眼样红斑**（中间红→白圈→外红）→ 莱姆病征象，立即就医
- 发热、头痛、肌肉酸痛 → 就医
- 保留取出的蜱虫（密封袋中），有助于医生诊断

## 四、蚂蟥（水蛭）叮咬

| 步骤 | 操作 |
|------|------|
| ① | 不要硬拉——口器会断在皮肤里 |
| ② | 撒盐、滴醋或酒精在蚂蟥身上，它会自行脱落 |
| ③ | 或用指甲从侧面轻轻"掀"开吸盘 |
| ④ | 伤口碘伏消毒，按压止血（蚂蟥分泌抗凝物质，出血会多一些） |

## 五、蝎子蜇伤

- 中国大部分蝎子毒性较弱，局部剧痛为主要症状
- 处理：清洗伤口+冰敷止痛+口服布洛芬
- 如出现流口水、出汗、肌肉抽搐、呼吸困难→中毒严重，立即就医
- 儿童、老年人被蜇伤应尽早就医

## 六、野外创伤处理

### 6.1 止血——野外条件下的加压止血

野外没有专业止血器材时：

| 方法 | 操作 |
|------|------|
| 直接压迫 | 用干净布（T恤撕成条）直接按压伤口，持续10分钟 |
| 加压包扎 | 纱布+绷带加压包扎，注意远端血运（手指/脚趾颜色和温度） |
| 止血带 | **仅用于危及生命的大出血**（如肢体离断），记录上止血带的时间，每30-60分钟松解一次 |

> ⚠️ 止血带是最后手段，不正确使用可导致肢体坏死截肢。小伤口绝不要用。

### 6.2 骨折固定——就地取材

- 用树枝、登山杖、卷起的睡垫做夹板
- 固定范围：骨折部位**上下两个关节**
- 在夹板和皮肤间垫软物
- 固定松紧以不阻断血运为度
- 开放性骨折（骨头刺出皮肤）：不要试图复位——消毒覆盖后固定，立即送医

### 6.3 伤口污染处理

野外伤口常被泥土、草木碎片污染：
1. 大量清水（饮用级别）**彻底冲洗**——这是预防感染最关键的一步
2. 可见异物用消毒镊子取出
3. 碘伏消毒
4. 无菌敷料覆盖
5. 深而窄的污染伤口（如被树枝刺伤）→ 需要打破伤风抗毒素

## 七、本章小结

蛇咬伤的核心是"静、低、固、送"——不动、低于心脏、压力固定、尽快送医，绝不用嘴吸毒。蜂蜇刮除毒刺、冰敷止痛，过敏体质随身带肾上腺素笔。蜱虫用镊子夹头垂直拔出，绝不硬拔或用化学品刺激。野外创伤止血首选直接压迫，止血带是最后手段。正确处理能救命，错误处理可能比伤情本身更致命。
