# 5.1 户外常见急症应对——远离医院时的自救法则

> 户外活动最特殊的地方在于：出事的时候你可能离最近的医院有几个小时甚至更远。在这种情况下，"第一时间正确处理"不是锦上添花，而是决定生死。

## 一、中暑——快速识别，立即降温

### 1.1 中暑的三个阶段

| 阶段 | 核心机制 | 症状 | 体温 | 处理 |
|------|---------|------|------|------|
| **热痉挛** | 出汗过多失盐 | 肌肉痉挛（小腿/腹部） | 正常或略高 | 阴凉处休息+喝含盐饮料 |
| **热衰竭** | 脱水+循环不足 | 大量出汗、苍白、头晕、恶心、乏力 | <40°C | 阴凉处平卧抬高腿+补液 |
| **热射病** | 体温调节中枢衰竭 | 皮肤**干热无汗**、意识模糊、抽搐 | **≥40°C** | 🔴 **立即降温+呼叫急救** |

> 🔴 **热射病的核心识别**：高热（>40°C）+ 意识障碍 + 皮肤干热无汗。这是**致命的急症**，死亡率极高，必须分秒必争。

### 1.2 中暑急救步骤

**热痉挛/热衰竭**：
1. 移至阴凉通风处，平卧，抬高下肢
2. 脱去多余衣物
3. 凉水擦拭身体 + 扇风降温
4. 补充含盐液体（运动饮料或淡盐水）
5. 如果30分钟无改善或症状加重→送医

**热射病（生命危险！）**：
1. **立即拨打120**
2. 在等待救援同时，**用一切方法快速降温**：
   - 将患者浸入冷水（最有效，如果条件允许）
   - 或用冷水浇淋、冰袋敷颈部/腋窝/腹股沟
   - 持续扇风
3. 如果患者意识不清且呕吐，侧卧防止误吸
4. 到达医院前不要停止降温措施

### 1.3 中暑预防

| 措施 | 说明 |
|------|------|
| 补水 | 出发前30分钟喝300-500ml水，活动中每15-20分钟喝150-200ml |
| 避开高温时段 | 户外活动避开11:00-15:00 |
| 着装 | 浅色、宽松、透气；遮阳帽+太阳镜 |
| 补盐 | 大量出汗时喝运动饮料或淡盐水，不是纯水 |
| 量力而行 | 感觉头晕、恶心、乏力时立即停止并休息 |

## 二、失温——不是只有冬天才会发生

### 2.1 什么是失温？

核心体温降至**35°C以下**即为失温。户外失温不只发生在严寒中——**大风、湿衣、疲劳**是失温的三大帮凶。15°C的天气如果衣服湿透再加风吹，同样可以导致失温。

### 2.2 失温的分级与识别

| 分级 | 核心体温 | 表现 |
|------|---------|------|
| **轻度** | 35-32°C | 剧烈寒战、手脚发麻、语速变慢、判断力下降 |
| **中度** | 32-28°C | 寒战停止（危险信号！）、意识模糊、动作笨拙 |
| **重度** | <28°C | 昏迷、呼吸浅慢、心跳微弱、瞳孔散大 |

### 2.3 失温急救——"避风、脱湿、保暖、补热"

| 步骤 | 操作 |
|------|------|
| **① 避风** | 立即移动到避风处（帐篷、岩石后、建筑物），切断风寒效应 |
| **② 脱湿** | 脱掉所有湿衣服，换上干衣服或用干燥的睡袋/毯子包裹 |
| **③ 保暖** | 包裹全身（包括头部），用救生毯（银色面向内）、睡袋、所有可用衣物 |
| **④ 补热** | 喝温热的含糖饮料（如果清醒能吞咽）；用暖宝宝或热水瓶敷**核心区域**（胸部、颈部、腹股沟，不要敷四肢） |

> 🔴 **失温急救禁忌**：
> - ❌ 不要按摩或摩擦四肢——使外周冷血回流心脏，可能诱发心律失常
> - ❌ 不要让患者自己走——失温者心肌应激性高，突然活动可能诱发室颤
> - ❌ 不要喝酒取暖——酒精扩张外周血管，加速热量流失
> - ❌ 不要快速复温——可能导致血压骤降

## 三、高原反应——海拔不是意志力能克服的

### 3.1 高原反应的分级

| 类型 | 症状 | 处理 |
|------|------|------|
| **急性高山病（AMS）** | 头痛+恶心/头晕/乏力/失眠中至少一项 | 停止上升、休息、用药 |
| **高原肺水肿（HAPE）** | 静息时呼吸困难、干咳→粉红色泡沫痰 | 🔴 **立即下撤！** |
| **高原脑水肿（HACE）** | 行走不稳、意识改变、幻觉 | 🔴 **立即下撤！危重！** |

### 3.2 高原反应的预防与用药

| 措施 | 说明 |
|------|------|
| 缓慢上升 | >3000m后每天上升不超过500m，每上升1000m休整一天 |
| **乙酰唑胺** | 预防用药，出发前1天开始服用（125-250mg/次，每日2次，处方药） |
| 布洛芬 | 缓解高原头痛 |
| **地塞米松** | 治疗严重AMS/HACE（处方药，仅用于紧急情况） |
| 吸氧 | 所有严重高原反应的辅助治疗 |

### 3.3 高原反应的处理原则

1. **头痛是第一个信号**——不要忽视，停下来评估
2. 轻度AMS：停止上升+休息+布洛芬止痛+多喝水，观察24小时
3. 如果症状加重或出现HAPE/HACE迹象：**唯一的正确选择是立即下撤**
4. "扛过去"是高原上最危险的想法

## 四、晕车/晕船/晕机

### 4.1 药物预防（出发前用药！）

| 药物 | 用法 | 注意 |
|------|------|------|
| 茶苯海明（乘晕宁）| 出发前30-60分钟服 | 有嗜睡副作用，服药后不开车 |
| 东莨菪碱贴片 | 出发前4小时贴于耳后 | 效果持续72小时 |

> 🔑 **关键提示**：晕车药必须在**出发前**服用——你已经开始晕了再吃药，效果大打折扣。

### 4.2 非药物方法

- 选择前排座位（大巴/轿车）或中部座位（船）
- 视线看远处地平线，不要看书/手机
- 保持通风
- 生姜片含服或姜茶
- 按压内关穴（手腕内侧横纹上方约三指宽处）

## 五、户外急救包建议

在家庭药箱基础上，户外出行应额外携带：

| 物品 | 用途 |
|------|------|
| 碘伏棉签（独立包装） | 伤口消毒 |
| 无菌纱布+弹性绷带 | 止血包扎 |
| 创可贴（防水） | 小伤口 |
| 三角巾 | 骨折固定、大创伤包扎 |
| 救生毯 | 失温急救、防晒 |
| 口服补液盐 | 脱水/腹泻/中暑 |
| 布洛芬 | 止痛、退热、高原头痛 |
| 氯雷他定 | 过敏反应 |
| 茶苯海明 | 晕车 |
| 蛇药片 | 毒蛇咬伤（备用，非首选治疗） |
| 镊子 | 取异物、拔刺、取蜱虫 |
| 安全别针 | 固定绷带/三角巾 |

## 六、本章小结

户外急救的核心逻辑是：**中暑立即降温、失温避风保暖、高反停止上升或下撤、晕车提前用药**。在远离医院的户外环境中，"第一时间做对"比"等到了医院再说"重要百倍。下一章将集中讨论户外最令人恐惧的意外——蛇虫叮咬与野外创伤的处理。
