## 二、急救流程速查

### 2.1 发热处理流程

```
体温 < 38.5°C  →  多喝水 + 物理降温 + 观察
体温 ≥ 38.5°C  →  服退烧药（成人：对乙酰氨基酚或布洛芬）
                 →  物理降温辅助
                 →  持续超过3天或伴有危险信号→就医
婴儿 < 3个月   →  任何发热立即就医
```

### 2.2 腹泻处理流程

```
急性腹泻（水样便、无高热）
  → 口服补液盐（每次稀便后补充）
  → 蒙脱石散
  → 饮食调整（白粥、烂面条）
  → 观察24-48小时

腹泻 + 高热/脓血便/剧烈腹痛
  → 不要止泻→立即就医
```

### 2.3 烫伤处理流程

```
Ⅰ度（红斑）或小面积浅Ⅱ度（小水疱）
  → 流动冷水冲15-20分钟
  → 不挑破水疱
  → 碘伏消毒 + 烫伤膏
  → 无菌敷料保护

大面积或深Ⅱ度及以上
  → 冷水冲 → 覆盖 → 立即去急诊
```

### 2.4 扭伤处理流程

```
伤后0-48小时
  → RICE：休息 + 冰敷 + 加压 + 抬高
  → 绝不热敷/按摩

伤后48小时后
  → 改为热敷
  → 逐步恢复活动

无法承重/明显畸形/定点骨痛
  → 拍X光片排除骨折
```

### 2.5 毒蛇咬伤处理流程

```
确认/疑似毒蛇咬伤
  → 保持静止不动
  → 咬伤部位低于心脏
  → 弹性绷带压力固定整个被咬肢体
  → 拨打120或用最快方式送医
  → 带上蛇的照片（帮助选用抗蛇毒血清）
  → 绝对禁止：用嘴吸/切开/冰敷/喝酒/跑步
```

### 2.6 中暑急救流程

```
热痉挛/热衰竭
  → 阴凉处 → 平卧抬腿 → 脱衣降温 → 补含盐液体

热射病（高热>40°C + 意识障碍 + 无汗）
  → 立即打120 + 同时全力降温（冷水浸泡/泼水/冰敷）
  → 这是致命急症，争分夺秒
```

## 三、必须就医的警示信号汇总

### 3.1 全身性危险信号（出现任一立即就医）

- 持续高热超过3天
- 意识模糊、嗜睡、难以唤醒
- 呼吸困难、嘴唇发紫
- 严重过敏反应（喉咙发紧、嘴唇肿胀、全身皮疹）
- 呕血、黑便（柏油样）、咯血
- 剧烈头痛伴颈项强直
- 突然发作的"一生中最剧烈的头痛"

### 3.2 儿童专属危险信号

- <3个月婴儿任何发热
- 精神萎靡、拒食、烦躁不安
- 呼吸急促、鼻翼煽动、肋间凹陷
- 脱水征（眼窝凹陷、皮肤弹性差、6小时无尿）
- 热性惊厥>5分钟或反复抽搐

### 3.3 老年人专属危险信号

- 突然意识改变、胡言乱语
- 不明原因的跌倒
- 精神萎靡、食欲突然明显下降
- 任何部位的持续疼痛不缓解

### 3.4 需要叫120（急救车）的情况

- 意识丧失或意识水平下降
- 呼吸停止或严重呼吸困难
- 严重胸痛（可能心梗）
- 大出血无法控制
- 严重过敏反应（过敏性休克）
- 毒蛇咬伤
- 严重创伤（高处坠落、车祸）
- 中毒（误服药物/化学品）

## 四、常用药品禁忌速查

| 药品 | 主要禁忌 |
|------|---------|
| 布洛芬 | 胃溃疡、严重肾衰、孕晚期、12岁以下儿童慎用 |
| 阿司匹林 | 12岁以下儿童绝对禁用（瑞氏综合征）、胃溃疡、出血倾向 |
| 对乙酰氨基酚 | 严重肝病、每日不超过2g |
| 吗丁啉（多潘立酮） | 心脏疾病（QT间期延长）、肝功能障碍 |
| 洛哌丁胺（易蒙停） | 12岁以下儿童禁用、细菌性腹泻禁用 |
| 复方感冒药 | 高血压（含伪麻黄碱者）、6岁以下儿童不推荐 |
