    64|## 二、急救流程速查
    65|
    66|### 2.1 发热处理流程
    67|
    68|```
    69|体温 < 38.5°C  →  多喝水 + 物理降温 + 观察
    70|体温 ≥ 38.5°C  →  服退烧药（成人：对乙酰氨基酚或布洛芬）
    71|                 →  物理降温辅助
    72|                 →  持续超过3天或伴有危险信号→就医
    73|婴儿 < 3个月   →  任何发热立即就医
    74|```
    75|
    76|### 2.2 腹泻处理流程
    77|
    78|```
    79|急性腹泻（水样便、无高热）
    80|  → 口服补液盐（每次稀便后补充）
    81|  → 蒙脱石散
    82|  → 饮食调整（白粥、烂面条）
    83|  → 观察24-48小时
    84|
    85|腹泻 + 高热/脓血便/剧烈腹痛
    86|  → 不要止泻→立即就医
    87|```
    88|
    89|### 2.3 烫伤处理流程
    90|
    91|```
    92|Ⅰ度（红斑）或小面积浅Ⅱ度（小水疱）
    93|  → 流动冷水冲15-20分钟
    94|  → 不挑破水疱
    95|  → 碘伏消毒 + 烫伤膏
    96|  → 无菌敷料保护
    97|
    98|大面积或深Ⅱ度及以上
    99|  → 冷水冲 → 覆盖 → 立即去急诊
   100|```
   101|
   102|### 2.4 扭伤处理流程
   103|
   104|```
   105|伤后0-48小时
   106|  → RICE：休息 + 冰敷 + 加压 + 抬高
   107|  → 绝不热敷/按摩
   108|
   109|伤后48小时后
   110|  → 改为热敷
   111|  → 逐步恢复活动
   112|
   113|无法承重/明显畸形/定点骨痛
   114|  → 拍X光片排除骨折
   115|```
   116|
   117|### 2.5 毒蛇咬伤处理流程
   118|
   119|```
   120|确认/疑似毒蛇咬伤
   121|  → 保持静止不动
   122|  → 咬伤部位低于心脏
   123|  → 弹性绷带压力固定整个被咬肢体
   124|  → 拨打120或用最快方式送医
   125|  → 带上蛇的照片（帮助选用抗蛇毒血清）
   126|  → 绝对禁止：用嘴吸/切开/冰敷/喝酒/跑步
   127|```
   128|
   129|### 2.6 中暑急救流程
   130|
   131|```
   132|热痉挛/热衰竭
   133|  → 阴凉处 → 平卧抬腿 → 脱衣降温 → 补含盐液体
   134|
   135|热射病（高热>40°C + 意识障碍 + 无汗）
   136|  → 立即打120 + 同时全力降温（冷水浸泡/泼水/冰敷）
   137|  → 这是致命急症，争分夺秒
   138|```

   140|## 三、必须就医的警示信号汇总
   141|
   142|### 3.1 全身性危险信号（出现任一立即就医）
   143|
   144|- 持续高热超过3天
   145|- 意识模糊、嗜睡、难以唤醒
   146|- 呼吸困难、嘴唇发紫
   147|- 严重过敏反应（喉咙发紧、嘴唇肿胀、全身皮疹）
   148|- 呕血、黑便（柏油样）、咯血
   149|- 剧烈头痛伴颈项强直
   150|- 突然发作的"一生中最剧烈的头痛"
   151|
   152|### 3.2 儿童专属危险信号
   153|
   154|- <3个月婴儿任何发热
   155|- 精神萎靡、拒食、烦躁不安
   156|- 呼吸急促、鼻翼煽动、肋间凹陷
   157|- 脱水征（眼窝凹陷、皮肤弹性差、6小时无尿）
   158|- 热性惊厥>5分钟或反复抽搐
   159|
   160|### 3.3 老年人专属危险信号
   161|
   162|- 突然意识改变、胡言乱语
   163|- 不明原因的跌倒
   164|- 精神萎靡、食欲突然明显下降
   165|- 任何部位的持续疼痛不缓解
   166|
   167|### 3.4 需要叫120（急救车）的情况
   168|
   169|- 意识丧失或意识水平下降
   170|- 呼吸停止或严重呼吸困难
   171|- 严重胸痛（可能心梗）
   172|- 大出血无法控制
   173|- 严重过敏反应（过敏性休克）
   174|- 毒蛇咬伤
   175|- 严重创伤（高处坠落、车祸）
   176|- 中毒（误服药物/化学品）
