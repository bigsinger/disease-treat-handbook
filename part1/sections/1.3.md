# 1.3 药品储存与有效期管理——药放对了才有效

> 药品是特殊的商品，储存不当会让好药变毒药。一瓶放错位置的胰岛素、一片受潮的阿司匹林，都可能带来严重后果。

## 一、药品储存的四大天敌

| 天敌 | 危害 | 避免方法 |
|------|------|---------|
| **高温** | 加速药品变质，蛋白类药物失活 | 常温储存（10-30°C），夏季炎热时部分药品需冷藏 |
| **潮湿** | 片剂受潮崩解、栓剂软化、胶囊粘连 | 不放浴室/厨房，药瓶盖紧，内置干燥剂勿丢弃 |
| **光照** | 紫外线破坏药物化学结构 | 保留原包装不拆出，不暴露在阳光直射处 |
| **空气** | 氧化变色、药效下降 | 开封后尽快用完，部分药品开封后用夹子封口 |

> 🔑 **口诀**：阴凉、干燥、避光、密封——这八个字是药品储存的核心。

## 二、不同剂型的储存要点

### 2.1 片剂与胶囊

- 保留在原包装中（铝箔泡罩或密封瓶），**不要提前拆出混装**
- 取药时手要干燥，不要一次倒出多粒再放回
- 瓶装药开封后，瓶盖内的**干燥剂不要丢弃**
- 变色、发黏、碎裂、有异味的片剂 → 立即丢弃

### 2.2 液体制剂

| 剂型 | 开封后使用期限 | 储存要点 |
|------|---------------|---------|
| 糖浆剂 | 冬季3个月，夏季1个月 | 阴凉处，不要冷藏（糖浆结晶） |
| 混悬液（如美林） | 按说明书，通常1-3个月 | 用前摇匀，用干净量杯 |
| 滴眼液 | 开封后1个月 | 阴凉处，瓶口勿接触任何表面 |
| 口服液（单支） | 开封即用 | 一次性用完 |

> ⚠️ **特别注意**：混悬液（如儿童布洛芬混悬液）用前必须**充分摇匀**——有效成分会沉底，不摇匀会导致每勺剂量不一致。

### 2.3 外用制剂

- 软膏、乳膏：盖紧盖子，避免进水
- 贴膏：密封防潮，避免失去黏性
- 滴眼液/滴耳液：瓶口**绝对不能接触皮肤或黏膜**，防止污染

### 2.4 需要冷藏的药品

| 药品类型 | 储存温度 | 特别注意 |
|---------|---------|---------|
| 胰岛素（未开封） | 2-8°C（冷藏） | **绝对不能冷冻**，冷冻后失效 |
| 胰岛素（已开封） | 室温（≤30°C） | 开封后1个月内用完 |
| 益生菌制剂 | 2-8°C（冷藏） | 部分产品可常温储存，看说明书 |
| 某些栓剂 | 2-8°C（冷藏） | 防止软化变形 |
| 某些生物制剂 | 2-8°C（冷藏） | 严格冷链 |

> 🔴 **关键误区**："放冰箱冷藏"不是"放冰箱就行"——要放**冷藏室（2-8°C）**，不是冷冻室。冷冻会破坏蛋白质类药物结构，使胰岛素等完全失效。

## 三、药品有效期：不只是看日期

### 3.1 有效期≠"一直有效到那天"

- 有效期的含义：**在规定的储存条件下、未开封时**，药品质量符合标准
- 一旦开封，有效期的意义就变了——很多药品开封后使用期限远短于包装上的有效期

### 3.2 开封后使用期限速查

| 剂型 | 开封后建议期限内用完 |
|------|-------------------|
| 瓶装片剂 | 6个月（干燥条件下） |
| 铝箔泡罩片剂 | 每次取用即密封，效期内均可 |
| 眼药水 | 开封后1个月 |
| 糖浆剂 | 冬季3个月，夏季1个月 |
| 软膏/乳膏 | 开封后3个月 |
| 胰岛素（已开封） | 4周（无论效期还有多长） |

### 3.3 怎样判断药品是否变质？

| 剂型 | 变质信号 |
|------|---------|
| 片剂 | 变色、碎裂、发黏、膨胀、有斑点或霉点 |
| 胶囊 | 粘连、变形、破裂、内容物漏出 |
| 糖浆 | 分层、沉淀（摇不散）、有气泡或酸臭味 |
| 软膏 | 出水、变色、有异味、质地不均 |
| 滴眼液 | 浑浊、沉淀、变色 |

> 🔑 **通用判断**：看、闻、摸——颜色变了、气味变了、质地变了的药品，不管有效期到没到，都不要再用。

## 四、过期药品处理

### 4.1 不要做的事

- ❌ **扔进垃圾桶**——可能被儿童或宠物误食
- ❌ **冲入马桶/下水道**——污染水源和土壤
- ❌ **卖给或送人**——违法且危险
- ❌ **继续使用**——"才过期几天应该没事"是最危险的想法

### 4.2 正确处理方式

1. **药品回收点**：许多医院、药店设有过期药品回收箱
2. **社区有害垃圾**：部分城市的有害垃圾分类接收过期药品
3. **自行处理**（无回收点时）：取出药品与咖啡渣、猫砂等杂物混合装入密封袋，再丢弃
4. **注意保护隐私**：撕去药瓶上的个人信息标签

## 五、家庭药箱定期检查清单

建议每**3-6个月**做一次药箱全面检查：

- [ ] 逐盒检查有效期，剔除过期药品
- [ ] 检查开封药品的状态（颜色/气味/质地）
- [ ] 补充已用完的常备药品
- [ ] 检查器械（体温计电池、剪刀镊子是否生锈）
- [ ] 重新确认药箱放在儿童够不到的地方

## 六、本章小结

药品储存的核心是防"四害"——高温、潮湿、光照、空气。不同剂型有不同的储存要求，开封后使用期限往往远短于包装有效期。定期检查药箱、正确处理过期药品，是每个家庭的健康必修课。第一篇到此结束，下一章我们将进入实战——呼吸系统常见病症的识别与处理。
