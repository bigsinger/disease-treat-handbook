# 2.1 呼吸系统：感冒、流感与咳嗽——分得清才治得对

> 感冒和流感只有一字之差，处理方式却天差地别。大多数呼吸系统小病可以在家处理，但前提是你得先分清楚：这是普通感冒、流感、还是细菌感染？

## 一、感冒 vs 流感：一张表分清

| 维度 | 普通感冒 | 流行性感冒 |
|------|---------|-----------|
| 病原体 | 鼻病毒、冠状病毒等 | 流感病毒（甲型/乙型） |
| 起病 | 渐进，1-3天慢慢加重 | **突然**，几小时内迅速恶化 |
| 发热 | 不发热或低热（<38.5°C） | **高热**（39-40°C），持续3-4天 |
| 全身症状 | 轻，能正常活动 | **重**——乏力、肌肉酸痛、头痛剧烈 |
| 呼吸道症状 | 鼻塞、流涕、打喷嚏为主 | 咳嗽、咽痛，鼻塞不突出 |
| 病程 | 5-7天自愈 | 1-2周，乏力可持续数周 |
| 并发症风险 | 低 | **高**——可致肺炎、心肌炎 |

> 🔑 **一句话区分**：感冒是"还能扛"，流感是"只想躺着"。

## 二、普通感冒的家庭处理

### 2.1 核心原则：对症不对因

感冒由病毒引起，**抗生素无效**。治疗目标是缓解症状，靠自身免疫力清除病毒。

### 2.2 症状 → 用药对应表

| 症状 | 药物选择 | 注意事项 |
|------|---------|---------|
| 发热/头痛/全身酸痛 | 对乙酰氨基酚 或 布洛芬 | 体温≥38.5°C时用，两种不混用 |
| 鼻塞 | 伪麻黄碱（复方感冒药常含）| 高血压患者慎用 |
| 流涕/打喷嚏 | 氯苯那敏（扑尔敏）| 有嗜睡副作用，睡前用 |
| 咳嗽（干咳） | 右美沙芬 | 痰多者不适用 |
| 咳嗽（有痰） | 氨溴索 / 乙酰半胱氨酸 | 多喝水帮助排痰 |

### 2.3 复方感冒药怎么选？

市面上大多数感冒药是复方制剂，看成分选：

| 商品名 | 主要成分 | 侧重症状 |
|--------|---------|---------|
| 白加黑（日片） | 对乙酰氨基酚+伪麻黄碱+右美沙芬 | 发热+鼻塞+咳嗽 |
| 白加黑（夜片） | 再加氯苯那敏 | 同上+帮助睡眠 |
| 感康 | 对乙酰氨基酚+金刚烷胺+氯苯那敏 | 发热+流涕+早期感冒 |

> ⚠️ **关键警告**：**不要**同时吃多种感冒药。先看成分表——对乙酰氨基酚出现在很多复方感冒药中，叠加极易超量。

### 2.4 不需要吃药的情况

- 轻微感冒（不发热、不严重影响生活）→ 多喝水、休息即可
- 维生素C对感冒的**预防和治疗作用证据有限**，不推荐大量服用
- 抗生素**对感冒病毒完全无效**——没有黄脓痰/黄鼻涕≠细菌感染

## 三、流感的识别与应对

### 3.1 什么时候要怀疑是流感？

- **突发高热**（39°C以上）+ 剧烈全身酸痛 + 明显乏力
- 如果正处流感流行季节，且有上述表现，大概率是流感

### 3.2 流感的家庭处理

| 措施 | 说明 |
|------|------|
| 退热 | 对乙酰氨基酚或布洛芬，体温≥38.5°C时用 |
| 休息 | 绝对卧床休息，不要去上班/上学 |
| 补水 | 大量饮水，发热出汗失水严重 |
| 隔离 | 佩戴口罩，与家人分餐，开窗通风 |

### 3.3 抗流感病毒药

- **奥司他韦（达菲）**：处方药，发病48小时内使用效果最好
- 流感季节如果医生确诊流感，会在48小时内开具
- **不推荐**自行购买预防性服用

### 3.4 流感何时必须就医？

- 持续高热超过3天
- 呼吸困难、胸痛
- 意识模糊、嗜睡难叫醒
- 儿童：拒食、烦躁不安、呼吸急促
- 老年人或有基础疾病者感染流感→尽早就医，流感对他们可能致命

## 四、咳嗽的处理

### 4.1 咳嗽是"朋友"还是"敌人"？

咳嗽是身体清除呼吸道异物和分泌物的保护性反射。**有痰的咳嗽不要强行镇咳**——把痰咳出来才是目的。

### 4.2 不同类型咳嗽的用药

| 咳嗽类型 | 特征 | 用药选择 | 常用药 |
|---------|------|---------|--------|
| **干咳**（无痰或少痰） | 喉咙痒、刺激性咳嗽 | 镇咳药 | 右美沙芬 |
| **湿咳**（痰多黏稠） | 咳声沉重、有痰音 | 祛痰药 | 氨溴索（沐舒坦）、乙酰半胱氨酸 |
| **夜间咳嗽** | 躺下加重 | 抗组胺+镇咳 | 氯苯那敏（睡前） |
| **感冒后咳嗽** | 感冒好了但咳不停 | 对症为主，大多自愈 | 持续超过3周需就医 |

### 4.3 家庭护理方法

- **蜂蜜**：成人1-2勺温水送服，对夜间咳嗽有缓解作用（**1岁以下婴儿禁用蜂蜜**）
- 蒸汽吸入：热水蒸气（注意防烫伤）
- 保持空气湿润：使用加湿器
- 多喝温水：稀释痰液，帮助排出

## 五、什么时候必须就医？

以下情况中的任意一条，不要在家处理：

- 发热超过3天不退
- 呼吸困难、胸痛
- 咳出黄绿色脓痰，且伴有高热（可能提示肺炎）
- 咳嗽超过3周不见好转
- 咯血
- 精神状态明显变差

## 六、本章小结

感冒对症处理，流感早识别早治疗，咳嗽分干湿选药。复方感冒药别叠加，抗生素对感冒无效。最重要的不是吃不吃药，而是休息+补水+观察。下一章将讨论消化系统的常见问题——腹泻、便秘和胃痛的家庭应对。
