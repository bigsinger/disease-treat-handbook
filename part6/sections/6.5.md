# 6.5 烧烫伤急救处理——冲脱泡盖送五字诀

> 烧伤和烫伤是最常见的家庭意外之一。厨房热油、开水壶、洗澡水、取暖器、烟花爆竹——危险无处不在。正确处理可以最大限度减轻伤害、减少疤痕；错误处理（涂酱油、牙膏、面粉等偏方）则会让伤情加重。

## 一、烧伤深度的识别

### 1.1 三度四分法

| 分度 | 损伤深度 | 外观 | 疼痛感 | 愈合时间 | 留疤风险 |
|------|---------|------|--------|---------|---------|
| **Ⅰ度（红斑型）** | 仅表皮 | 红斑、干燥、无疱 | 灼痛明显 | 3-7天脱屑愈合 | 不留疤 |
| **浅Ⅱ度（水疱型）** | 真皮浅层 | 大水疱、基底潮红、渗液多 | **剧痛** | 1-2周 | 一般不留疤，可能色素沉着 |
| **深Ⅱ度** | 真皮深层 | 小水疱、基底红白相间、渗液少 | 疼痛**迟钝** | 3-4周 | 留疤 |
| **Ⅲ度（焦痂型）** | 全层皮肤+皮下 | 蜡白/焦黄/炭化、皮革样 | **不痛**（神经末梢已破坏） | 需植皮 | 严重留疤、功能障碍 |

> 🔑 **关键**：浅Ⅱ度最痛（神经暴露），Ⅲ度反而不痛（神经坏死）。不能以疼痛程度判断严重程度。

### 1.2 烧伤面积估算——手掌法

将伤者本人五指并拢的手掌面积视为其体表面积的 **1%**，快速估算烧伤面积。

| 烧伤面积 | 处理级别 |
|---------|---------|
| 成人 >10% Ⅱ度以上 | **立即拨打120** |
| 儿童 >5% Ⅱ度以上 | **立即拨打120** |
| Ⅲ度烧伤任何面积 | **立即拨打120** |
| 面部、手、足、会阴、关节部位 | **立即拨打120**（无论面积大小） |

## 二、急救五字诀——冲、脱、泡、盖、送

> ⚠️ 此流程适用于**热力烧伤**（开水、热油、火焰、蒸汽等）。化学烧伤和电烧伤见后续专门章节。

### 2.1 冲——冷水冲洗

| 操作要点 | 说明 |
|---------|------|
| 水温 | **流动自来水（15-25℃）**，不要用冰水 |
| 时间 | **至少冲 15-20 分钟**，直到疼痛明显缓解 |
| 范围 | 水流从伤口中央向周围冲洗，不要直接冲击伤口 |
| 禁忌 | **不要用冰块直接敷**——血管收缩加重组织坏死 |

> 🔴 **为什么不能冰敷？** 烧伤后局部血管已经受损，冰敷会使血管进一步收缩，加重组织缺血坏死。

### 2.2 脱——去除衣物

| 操作要点 | 说明 |
|---------|------|
| 边冲边脱 | 在冷水中进行，减轻疼痛 |
| 剪开勿扯 | 衣服粘连在伤口上时，**用剪刀剪开**，不要硬扯 |
| 去除饰品 | 戒指、手镯、手表等——组织肿胀后会嵌顿，造成二次损伤 |

### 2.3 泡——浸泡止痛

| 操作要点 | 说明 |
|---------|------|
| 适用 | 四肢中小面积烧伤，用于持续止痛 |
| 水温 | 15-25℃冷水 |
| 时间 | 15-30分钟 |
| 禁忌 | 大面积烧伤（>10%）不宜长时间浸泡——体温过低风险 |

### 2.4 盖——覆盖保护

| 操作要点 | 说明 |
|---------|------|
| 材料 | **无菌纱布** > 干净棉布/毛巾 > 保鲜膜（清洁面） |
| 方式 | 轻轻覆盖，不要包裹太紧 |
| 禁忌 | **不要涂任何东西**——酱油、牙膏、香油、蛋清、面粉都禁用 |

> 🔴 **为什么不能涂偏方？** ①增加感染风险 ②干扰医生判断创面深度 ③清理时需要擦除，加重疼痛和二次损伤。

### 2.5 送——及时就医

- Ⅰ度烧伤 → 可自行冷敷处理，涂抹烫伤膏
- 浅Ⅱ度以上或特殊部位（面、手、会阴、关节）→ **立即就医**
- 儿童、老人、糖尿病患者 → 任何Ⅱ度以上烧伤都应就医

## 三、特殊类型烧伤

### 3.1 化学烧伤（酸、碱）

| 步骤 | 操作 |
|------|------|
| **① 脱** | 立即脱去被污染衣物，用大量流动水冲洗 |
| **② 冲** | **冲洗至少30分钟**（比热力烧伤时间更长） |
| **③ 不中和** | **不要用酸碱中和**——中和反应产热会加重热损伤 |
| **④ 化学品** | 干石灰等遇水产热的化学品 → 先**刷掉**粉末再冲洗 |
| **⑤ 眼部** | 化学液体溅入眼睛 → 见 [6.6 眼部急症处理](./6.6.md) |

### 3.2 电烧伤

电烧伤的特点是"**入口小、内部损伤大**"——表面可能只是一个点状焦痂，但皮下组织、肌肉、血管、神经损伤广泛。

| 操作 | 说明 |
|------|------|
| 安全第一 | 先断电再碰伤者（同[6.4 触电急救](./6.4.md)的安全原则） |
| 覆盖 | 无菌敷料覆盖进/出口伤口 |
| 送医 | **所有电烧伤者必须就医**——隐匿性内脏损伤和迟发性心律失常可以致命 |

### 3.3 呼吸道烧伤（吸入性损伤）

| 高危场景 | 警示信号 |
|---------|---------|
| 密闭空间火灾 | 声音嘶哑、咳嗽带黑色痰 |
| 面部烧伤 | 鼻毛烧焦、口鼻周围烟灰 |
| 蒸汽吸入 | 呼吸困难、喘鸣 |

> 🔴 呼吸道烧伤是**危及生命**的急症——气道水肿可能在数分钟内完全阻塞呼吸。发现上述信号**立即拨打120**。

## 四、水疱处理——不要挑破

| ✅ 正确 | ❌ 错误 |
|--------|--------|
| 小水疱（<2cm）不挑破，覆盖保护 | 用针挑破、用指甲掐破 |
| 大水疱由医生在无菌条件下抽液 | 自行撕掉水疱皮 |
| 水疱自然破裂后保留疱皮覆盖 | 薄皮撕掉露出创面 |

> 🔑 水疱皮是天然的**生物敷料**——保护新生上皮、防止感染、减少疼痛。

## 五、烧烫伤常见误区

| 误区 | 真相 |
|------|------|
| "涂酱油/牙膏/蛋清" | 增加感染风险，干扰医生判断，清理时造成二次伤害 |
| "冰敷" | 血管收缩加重组织坏死，还可能冻伤 |
| "水疱挑破好得快" | 水疱皮是天然保护层，挑破增加感染风险 |
| "伤口要保持干燥" | 湿润环境更利于愈合，无菌敷料+烫伤膏即可 |
| "烧伤不严重不用去医院" | 浅Ⅱ度以上、特殊部位、儿童老人——都建议就医 |

## 六、家庭烫伤药膏使用

| 药品（通用名/商品名） | 用途 | 注意 |
|----------------------|------|------|
| 磺胺嘧啶银乳膏 | 预防感染，适用于Ⅱ度烧伤 | 磺胺过敏者禁用 |
| 湿润烧伤膏（美宝） | 促进愈合、减轻疼痛 | 应在医生指导下使用 |
| 京万红软膏 | 轻度烧烫伤 | 只适用于Ⅰ度 |
| 重组人表皮生长因子凝胶 | 促进愈合 | 需冰箱冷藏保存 |

> ⚠️ 所有用药建议仅供参考。大面积或深度烧伤请务必就医。

## 七、本章小结

烧烫伤急救记住**五字诀**：冲（冷水15-20分钟）、脱（剪开粘连衣物）、泡（冷水平浸泡止痛）、盖（无菌敷料覆盖）、送（Ⅱ度以上就医）。四大禁忌：不涂偏方、不冰敷、不挑疱、不硬扯衣服。特殊烧伤（化学、电、呼吸道）有各自专门的处理要点。水疱是天然保护层，不要主动破坏。
