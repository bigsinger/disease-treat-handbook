# 6.3 严重出血控制与止血带——不要让伤员在你面前流干血

> 一个成年人体内约有4-5升血液。股动脉破裂可以在2-3分钟内让人失血致死——比心脏骤停更快。严重出血的控制必须优先于所有其他急救措施，包括CPR。

## 一、出血类型识别

| 出血类型 | 血液颜色 | 流出方式 | 危险程度 |
|---------|---------|---------|---------|
| **动脉出血** | 鲜红色 | **喷射状**，随心跳搏动喷出 | 🔴 致命——几分钟内失血致死 |
| **静脉出血** | 暗红色 | 持续涌出 | 🟡 严重——可控但需加压 |
| **毛细血管出血** | 红色 | 渗血 | 🟢 轻微——一般自行止血 |

> 家庭场景下的擦伤、割伤处理见第3.2章。本章讨论的是**喷涌而出的、可能致死的严重出血**。

## 二、止血方法阶梯——从简单到极端

### 2.1 第一阶梯：直接压迫（适用于90%的出血）

| 步骤 | 操作 |
|------|------|
| **① 直接按压** | 用干净纱布/布/毛巾**直接按在出血点上** |
| **② 持续用力** | **保持持续压力至少10分钟**——不要频繁掀开看"止住了没" |
| **③ 加厚** | 如果血液浸透敷料，**不要取下**——在上面再加一层继续压 |
| **④ 加压包扎** | 出血减缓后用弹性绷带加压包扎，力度以远端能摸到脉搏为宜 |

> 🔴 **致命误区**：很多人在按压一分钟后掀开看看——结果刚形成的血凝块被扯掉，重新出血，前功尽弃。**压上去就别拿开。**

### 2.2 第二阶梯：止血敷料（深部伤口）

| 产品 | 使用方法 |
|------|---------|
| 止血纱布（含壳聚糖/高岭土） | 塞入伤口深处，直接压迫在出血点上，外面再加压包扎 |
| 明胶海绵 | 同止血纱布，用于深而窄的伤口 |
| 紧急情况替代 | 如果没有专业止血产品，**干净的布压住比什么都不做强** |

### 2.3 第三阶梯：止血带——最后手段

> ⚠️ **止血带只用于四肢的危及生命的大出血**——喷射状动脉出血、直接压迫无效、或需要解放双手处理其他伤者时。

## 三、止血带的正确使用

### 3.1 什么时候用止血带？

| 适用情况 | 不适用情况 |
|---------|-----------|
| 动脉喷射性出血 | 毛细血管渗血 |
| 直接压迫10分钟后仍无法控制 | 头颈部出血（不能用止血带！） |
| 肢体部分/完全离断 | 躯干部出血（改用填塞+直接压迫） |
| 多处伤员需同时处理（解放双手） | 能通过直接压迫控制的出血 |

### 3.2 止血带放置位置

| 原则 | 说明 |
|------|------|
| **高位** | 放在出血点**上方5-8cm**处（近心端），越靠近躯干越好 |
| **单骨区** | 上臂放在腋窝和肘之间；大腿放在腹股沟和膝之间 |
| **绝对不要** | ❌ 关节上、❌ 骨折处、❌ 直接在伤口上 |

> 上臂中下段有桡神经走行，止血带放在此处可能永久损伤神经 → **上臂放在靠近腋窝的高位**。

### 3.3 操作步骤

| 步骤 | 操作 |
|------|------|
| **① 暴露** | 露出肢体，移除或剪开衣物 |
| **② 放置** | 止血带穿过肢体，放在高位 |
| **③ 收紧** | 拉紧束带至出血停止 + 远端脉搏消失为止 |
| **④ 固定** | 固定绞棒，防止松脱 |
| **⑤ 记录时间** | **在伤员额头或止血带上标注上止血带的时间**——这是最重要的步骤 |
| **⑥ 不要覆盖** | 止血带必须保持暴露可见——让后续医护一眼看到 |

### 3.4 止血带的关键铁律

| 铁律 | 说明 |
|------|------|
| **标注时间** | 没有时间记录的止血带是医疗事故 |
| **不要松解** | 上了止血带后**不要中途松解**——蓄积的毒素回流可能致命 |
| **超过2小时** | 止血带超过2小时，肢体坏死风险急剧增加——但松解的决定只能由医生做出 |
| **疼痛是正常的** | 止血带会很痛——不要因为伤员叫痛就松开 |

### 3.5 临时止血带——没有专业器械时

在等待专业急救或没有专业止血带时：

1. **最有效的临时方案**：宽度至少5cm的布条（T恤撕条、皮带、领带） + 一根硬棒（笔、树枝、螺丝刀）作为绞棒
2. 打结后插入绞棒，旋转收紧直到出血停止
3. 固定绞棒防止回旋

> ❌ **不要用铁丝、电线、细绳、鞋带等细窄物品做止血带**——它们会像刀一样切割皮肤和下方的神经血管。

## 四、特殊部位出血处理

### 4.1 头颈部出血

**不能用止血带！** 处理方法：

- 直接压迫（注意不要压迫气道）
- 头皮出血往往看起来很吓人但出血量不大——持续按压即可
- 颈部大血管出血：手指直接按压出血点，**绝不松手**直到医生接手

### 4.2 躯干出血（胸部/腹部）

**不能用止血带！** 处理方法：

| 部位 | 方法 |
|------|------|
| 胸壁 | 开放性气胸→用不透气材料（塑料布/救生毯）盖住伤口，三边密封留一边排气 |
| 腹部 | 不要试图把脱出的内脏塞回去→用湿纱布覆盖+宽松包扎 |
| 腋窝/腹股沟 | 填塞+直接压迫——用止血纱布或干净布塞入伤口，外面持续加压 |

### 4.3 异物刺入

> 🔴 **绝对不要把刺入身体的异物拔出来！**

异物可能正堵住破损的血管——拔出等于打开血龙头。

| 操作 | 说明 |
|------|------|
| 固定异物 | 用纱布卷或布在异物周围垫高，胶带固定防止晃动 |
| 不要拔出 | 让医生在手术室里有控制地取出 |
| 快速送医 | 这种情况必须尽快手术处理 |

### 4.4 断肢处理

| 步骤 | 操作 |
|------|------|
| ① 伤员 | 止血带控制出血，尽快送医 |
| ② 断肢 | 用干净纱布包裹→放入密封塑料袋→塑料袋放入冰水混合的容器（**不要直接接触冰块**） |
| ③ 标记 | 标注伤员姓名和断肢时间 |
| ④ 送医 | 断肢随伤员一同送医 |

> 🔑 断肢在低温下可存活6-8小时（手指更长）。**不要**用酒精浸泡、不要直接放在冰上（冻伤组织）。

## 五、出血控制的常见误区

| 错误做法 | 正确做法 |
|---------|---------|
| ❌ 频繁掀开看止血效果 | ✅ 持续按压，10分钟后再评估 |
| ❌ 止血带放在关节上 | ✅ 放在单骨区（上臂高位或大腿高位） |
| ❌ 用细绳/铁丝当止血带 | ✅ 宽度至少5cm的布条 |
| ❌ 拔出刺入的异物 | ✅ 固定异物不晃动，送医处理 |
| ❌ 止血带中途松解 | ✅ 上紧后不再动，由医生决定 |
| ❌ 往伤口上撒药粉（云南白药等） | ✅ 直接压迫是唯一有效的止血方法 |

## 六、本章小结

严重出血的三级阶梯：直接压迫（90%情况足够）→ 止血敷料填塞（深部伤口）→ 止血带（危及生命且他法无效的四肢出血）。上了止血带必须标注时间，绝不中途松解。异物刺入不拔出，断肢低温保存。头颈和躯干出血不能用止血带。大出血的抢救窗口比心脏骤停更短——先止血，再做其他。
