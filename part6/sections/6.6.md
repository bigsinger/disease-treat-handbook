# 6.6 眼部急症处理——异物、化学伤与钝挫伤

> 眼睛是人体最脆弱也最重要的器官之一。眼部意外在日常生活中极为常见——灰尘入眼、洗发水溅入、炒菜油溅、化学品飞溅、运动撞击等。正确处理可以保护视力；错误处理（揉眼、用不洁物挑取异物）则可能导致永久性损伤。

## 一、眼部异物的处理

### 1.1 结膜/角膜表面异物（灰尘、沙粒、睫毛）

| 步骤 | 操作 |
|------|------|
| **① 不揉眼** | **绝对不要揉眼**——揉擦会使异物嵌入更深或划伤角膜 |
| **② 眨眼刺激** | 轻闭眼，让泪液自然冲刷——大多数小异物会被冲走 |
| **③ 冲洗** | 如果眨眼无效，用**无菌生理盐水**或**干净流水**从内眼角向外眼角冲洗 |
| **④ 翻眼睑** | 上眼睑翻起（用棉签轻压上眼睑边缘），检查是否有异物附着在眼睑内侧 |
| **⑤ 湿棉签** | 如果异物可见且位置表浅，用**湿润的无菌棉签**轻轻粘取 |

### 1.2 什么情况必须就医

| 情况 | 原因 |
|------|------|
| 异物**嵌入**眼球（不是浮在表面） | 自己取出可能加重损伤 |
| 高速飞溅物（金属碎屑、砂轮火花） | 可能已穿透眼球，表面伤口不明显 |
| 冲洗后异物感仍持续 | 可能有角膜擦伤，需要荧光素染色检查 |
| 视力下降、畏光加重 | 提示角膜损伤或眼内炎症 |
| 戴隐形眼镜时异物入眼 | 先取出隐形眼镜再处理 |

### 1.3 角膜擦伤的识别

异物擦过角膜表面后会留下擦伤，表现为：
- **剧烈疼痛**（角膜神经末梢最密集）
- **严重畏光流泪**
- **异物感持续不退**（即使异物已不存在）
- **视力模糊**

处理：闭眼休息，**不要自行滴任何眼药水**（含激素的眼药水会加重感染），尽快眼科就诊。

## 二、化学性眼灼伤——争分夺秒

> 🔴 化学液体溅入眼睛是**眼科最紧急的情况之一**。酸碱物质可在数分钟内造成不可逆的视力损伤。**第一时间冲洗，再打电话。**

### 2.1 冲洗原则

| 要点 | 说明 |
|------|------|
| **立即** | 在场就能做，**不要等120，先冲洗** |
| **大量** | 至少1000ml（约2瓶矿泉水）持续冲洗 |
| **彻底** | 冲洗至少**15-30分钟** |
| **充分暴露** | 用手指撑开眼睑，确保冲洗液到达结膜穹隆部 |
| **从内到外** | 从内眼角向外眼角冲洗，防止污染物流入另一只眼 |

### 2.2 各类化学物处理

| 化学品类型 | 常见来源 | 冲洗要点 |
|-----------|---------|---------|
| **酸性**（盐酸、硫酸、醋酸） | 洁厕灵、电池液、食醋 | 大量清水冲洗30分钟 |
| **碱性**（氢氧化钠、石灰、氨水） | 管道疏通剂、石灰、水泥、清洁剂 | **更危险**——碱可穿透角膜深层。冲洗**至少30分钟** |
| **干石灰** | 建筑工地、装修 | **先刷掉粉末再冲水**——遇水产热加重烧伤 |
| **超能胶（502等）** | 家庭维修 | 不要硬扯，温水冲洗后用**抗生素眼膏软化**，眼科就诊 |
| **辣椒水/防狼喷雾** | 意外误喷 | 大量清水冲洗，不要揉眼，通常不会造成永久损伤 |

> 🔴 **碱烧伤比酸烧伤更危险**——酸使蛋白质凝固形成屏障，碱能穿透组织深层持续损伤。

### 2.3 化学伤就医指征

- **所有化学性眼灼伤都应去眼科急诊**——即使冲洗后感觉好转，也需要裂隙灯检查确认角膜无损伤
- 就医时告知医生化学品的名称/成分（带包装去最好）

## 三、眼部钝挫伤（撞击伤）

### 3.1 常见场景

- 球类撞击（羽毛球、篮球）
- 拳头/肘部撞击
- 跌倒碰撞
- 弹弓/玩具枪

### 3.2 现场判断

| 症状 | 可能问题 | 处理 |
|------|---------|------|
| 眼睑肿胀、淤青（"熊猫眼"） | 软组织挫伤 | 伤后24小时内冷敷（每次15分钟），24小时后热敷促进淤血吸收 |
| 白眼球片状出血 | 结膜下出血 | 通常1-2周自行吸收，不影响视力；如反复出现需查血压和凝血功能 |
| 视力下降、眼前漂浮物增多 | 可能视网膜脱离/玻璃体出血 | **立即眼科急诊** |
| 复视（看东西重影） | 可能眼眶骨折 | **立即眼科急诊** |
| 眼球活动受限 | 眼眶骨折或肌肉嵌顿 | **立即眼科急诊** |

> 🔴 钝挫伤的"危险信号"：**视力下降、复视、眼前黑幕/闪光感、眼球突出/内陷**——任何一项都需立即就医。

## 四、眼部切割伤与穿透伤

| 操作 | 说明 |
|------|------|
| **不要冲洗** | 不同于化学伤，穿透伤冲洗可能使眼内容物溢出 |
| **不要按压** | 不要按压眼球 |
| **不要试图取出异物** | 如果异物刺入眼球——**留在原位**，用纱布圈固定后送医 |
| **遮盖** | 用**硬质眼罩**（纸杯底部剪开）盖住，不要触碰眼球 |
| **双眼遮盖** | 可考虑遮盖双眼减少眼球转动 |

## 五、紫外线眼损伤（电光性眼炎）

### 5.1 病因

长时间暴露于强紫外线——电焊弧光（"电焊眼"）、雪地反射阳光（"雪盲"）、紫外线消毒灯、长时间海边不戴太阳镜。

### 5.2 症状

| 症状 | 发作时间 |
|------|---------|
| 剧烈眼痛、严重畏光、大量流泪 | 暴露后 **3-12 小时**发作 |
| 眼睑痉挛（睁不开眼） | 剧痛时出现 |
| 异物感 | 持续存在 |

### 5.3 处理

| 步骤 | 操作 |
|------|------|
| ① | 脱离紫外线环境，进入暗室 |
| ② | 冷敷闭眼休息 |
| ③ | **眼科急诊**——需要表面麻醉+抗生素眼膏+散瞳药 |
| ④ | 通常24-48小时角膜上皮修复后疼痛缓解 |

> ⚠️ 不要自行买眼药水滴——含麻醉成分的眼药水（如丁卡因）频繁使用会抑制角膜上皮愈合，加重损伤。

## 六、家庭眼部急救箱推荐

| 物品 | 用途 |
|------|------|
| 无菌生理盐水（小支独立包装） | 眼部冲洗 |
| 荧光素钠试纸条 | 角膜擦伤筛查（需在医生培训后使用） |
| 无菌纱布/棉签 | 取异物、覆盖 |
| 硬质眼罩 | 穿透伤保护 |
| 抗生素眼膏（妥布霉素/红霉素） | 角膜擦伤后预防感染（医生处方后备用） |

> ⚠️ 不要自行购买含激素的眼药水（如地塞米松、可的松）——会抑制免疫，使感染扩散。

## 七、眼部急救"三不"原则

| 🚫 禁忌 | 原因 |
|--------|------|
| **不揉眼** | 揉眼会让异物嵌入更深、擦伤角膜 |
| **不随便滴药** | 在医生明确诊断前，滴错药可能加重病情 |
| **不拖延** | 视力下降、剧烈疼痛、化学品入眼——**立即就医** |

## 八、本章小结

眼部急症的通用处理原则：异物——不揉、冲洗、用湿棉签轻取，嵌入的不要自己动；化学伤——争分夺秒、立即大量冲水30分钟、不要中和、再就医；钝挫伤——视力下降是危险信号；穿透伤——不要冲洗、不要按压、异物留置原位、硬质眼罩保护。记住"**三不**"：不揉、不乱滴药、不拖延。分秒之间可能就是视力永久损失与保留的区别。第六篇到此结束，急救技能的精髓在于"宁可学了用不上，不可要用时没学过"。
