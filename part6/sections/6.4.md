# 6.4 常见意外急救——休克、癫痫、溺水、触电的现场处置

> 前面的章节讲了"最致命"的三种情况——窒息、心脏骤停、大出血。本章补充另外几种常见的严重意外——它们的共同特点是：现场处理得当可以救命，处理错误可能让情况恶化甚至致命。

## 一、休克——不是"吓晕了"，是循环衰竭

### 1.1 什么是休克？

休克是**有效循环血量不足导致组织器官灌注不良**的综合征。简单说：身体里的血不够用了，器官在"挨饿"。

> ⚠️ "休克"是一种可以致死的急症，不是"受到惊吓"或"情绪激动"——不要混淆。

### 1.2 休克的识别

| 早期信号 | 晚期信号 |
|---------|---------|
| 皮肤苍白、湿冷 | 意识模糊、反应迟钝 |
| 脉搏快而弱（>100次/分） | 嘴唇指甲发紫 |
| 呼吸急促 | 无尿 |
| 烦躁不安、口渴 | 血压下降（晚期才出现） |

> 🔑 **关键认知**：血压下降是休克**晚期**的表现——等到血压下降再识别就已经晚了。看皮肤、脉搏、意识来判断。

### 1.3 休克急救——"平卧、抬高、保暖、不喂食"

| 步骤 | 操作 | 说明 |
|------|------|------|
| **① 平卧** | 让伤员平躺，头部不要垫高 | 保证大脑供血 |
| **② 抬高下肢** | 双腿抬高约30cm（如果下肢无骨折） | 利用重力将血液回流到核心器官 |
| **③ 保暖** | 盖上毯子或衣物 | 休克时体温调节功能受损 |
| **④ 处理原发因** | 止血（如果在出血）、固定骨折 | 原发问题不解决，休克会恶化 |
| **⑤ 禁食禁水** | **什么都不能吃不能喝** | 可能需要紧急手术，胃内容物增加麻醉风险 |

> 🔴 **为什么不能喝水？** 休克伤员可能随时需要紧急手术。胃里有水/食物，全麻时可能反流误吸，导致致命的吸入性肺炎。口渴是休克的症状之一——用湿棉签湿润嘴唇缓解，但绝对不要给水喝。

### 1.4 过敏性休克——特殊类型的紧急情况

出现以下症状的组合（见3.1章荨麻疹部分的紧急情况），是过敏性休克：

- 全身荨麻疹 / 嘴唇眼睑肿胀 / 喉咙发紧 / 喘息 / 呼吸困难 / 头晕
- → 如有肾上腺素笔（EpiPen），立即在大腿外侧注射
- → **同时拨打120**
- → 平卧抬高腿（如果呼吸困难则半坐位）

## 二、癫痫大发作——不要往嘴里塞东西！

### 2.1 识别

- 突然意识丧失、倒地
- 全身强直→阵挛（抽搐）
- 可能口吐白沫、牙关紧咬
- 通常持续1-3分钟后自行停止
- 发作后意识模糊、嗜睡（发作后状态）

### 2.2 急救——保护，不干预

| ✅ 该做的事 | ❌ 不该做的事 |
|-----------|-------------|
| 移开周围危险物品 | 往嘴里塞任何东西（会咬断、吞入或伤及施救者手指） |
| 头下垫软物（衣物）防撞 | 强行按压肢体（会导致骨折或脱臼） |
| 发作结束后侧卧（复苏体位） | 掐人中（无效且可能造成外伤） |
| 记录发作持续时间 | 试图喂药喂水（发作时无法吞咽） |
| 陪伴直到完全清醒 | 约束绑缚 |

### 2.3 什么情况需要叫120？

- 发作持续**超过5分钟**（癫痫持续状态——可致死）
- 一次发作结束后**意识未恢复**又开始第二次发作
- 在水中发作
- 发作导致外伤
- 这是患者**第一次**发作
- 患者是孕妇

## 三、溺水——先通气，再按压

### 3.1 水中救援的安全原则

> 🔴 **第一原则：保证自身安全！** 每年都有施救者因为贸然下水而溺亡。

| 操作 | 说明 |
|------|------|
| 伸 | 用竹竿、树枝伸向溺水者 |
| 抛 | 抛绳子、救生圈、浮板 |
| 划 | 划船接近 |
| 游 | 只有受过专业救生训练的人才能下水 |

### 3.2 救上岸后的急救

溺水是窒息性心脏骤停，CPR的顺序与标准不同：

| 步骤 | 操作 |
|------|------|
| **① 判断** | 无反应 + 无正常呼吸 → 开始CPR |
| **② 先通气** | **先做5次人工呼吸**（溺水者体内严重缺氧） |
| **③ CPR循环** | 5次人工呼吸后 → 30次按压 : 2次吹气 |
| **④ AED** | 擦干胸部皮肤后使用AED（可用） |
| **⑤ 不要控水** | **不要倒吊、不要拍背控水**——耽误CPR时间，且控出的水是胃里的，不是肺里的 |

### 3.3 溺水急救关键误区

| 误区 | 真相 |
|------|------|
| "要先把水倒出来" | 肺里的水已经进入血液循环，倒不出来。CPR产生的胸腔压力可以排出部分水 |
| "还在水里就开始CPR" | 在**硬地上**才能做有效按压。先拖上岸 |
| "呼吸恢复了就不管了" | 溺水后可能出现"二次溺水"——数小时后肺水肿进展。任何溺水者都应去医院观察 |

## 四、触电——先断电，再救人

### 4.1 安全第一原则

> 🔴 触电急救的**第一且最重要**的原则：**在断开电源之前，绝对不要触碰伤者！** 否则你会成为第二个伤者。

| 操作 | 说明 |
|------|------|
| 低压电（家庭220V） | 拔插头、关闭电闸、用干燥木棍/塑料制品挑开电线 |
| 高压电 | **保持至少8米距离**，立即拨打120+电力部门，绝不靠近 |
| 雷击 | 可以立即接触（雷击后没有残余电荷），优先处理呼吸心跳停止者 |

### 4.2 脱离电源后的处理

| 步骤 | 操作 |
|------|------|
| ① 判断 | 检查反应和呼吸 |
| ② CPR | 无反应无呼吸 → 立即CPR（先按压，30:2） |
| ③ AED | 可以用——先确保环境干燥 |
| ④ 烧伤 | 触电进/出口可能有深度烧伤——无菌敷料覆盖 |
| ⑤ 送医 | 所有触电者都应就医——即使看起来没事，可能有隐匿的内脏损伤或迟发性心律失常 |

## 五、复苏体位——防止窒息的安全姿势

当伤者有呼吸但意识不清时，将其置于**复苏体位**可防止舌头后坠堵塞气道，以及呕吐物误吸。

### 5.1 操作步骤

1. 将伤者靠近你一侧的手臂向上伸直
2. 将对侧手臂弯曲，手背贴于面颊
3. 弯曲对侧膝盖
4. 拉膝盖将身体翻向自己一侧
5. 上面腿的膝盖弯曲着地，保持稳定
6. 头后仰保持气道开放
7. 每30分钟翻一次身

> 🔑 **什么时候用**：有正常呼吸但意识不清；癫痫发作后；醉酒昏迷但呼吸正常；等待急救到达时。

## 六、脊柱损伤——疑似一律按有损伤处理

| 场景 | 处理 |
|------|------|
| 高处坠落、车祸、头部外伤、跳水受伤 | **不要移动患者**——除非环境危险（火灾、爆炸等） |
| 必须移动时 | 多人搬运，保持**头-颈-躯干一条直线**，没有扭转 |
| 骑摩托车/单车摔伤 | 不要摘头盔——可能掩盖颈椎损伤的二次伤害 |

## 七、各场景急救优先级速查

| 场景 | 第一步 | 第二步 | 第三步 |
|------|--------|--------|--------|
| 发现倒地者 | 确保环境安全 | 拍喊判断反应 | 无反应→检查呼吸→CPR |
| 严重车祸 | 确保安全 | 优先处理大出血和无呼吸者 | 不要移动可能有脊柱损伤的人 |
| 多人受伤 | 先处理**不出声**的（可能气道梗阻或无呼吸） | 再处理能喊叫的 | — |
| 火灾现场 | 先转移到安全区 | 再开始急救 | 烧伤：冲冷水→覆盖→送医 |

## 八、本章小结

休克的急救是"平卧、抬高腿、保暖、不给吃喝"——记住休克伤员不能喝水。癫痫发作的保护原则是"不干预"——移开危险物品、垫头、不塞嘴、不按压。溺水急救先做5次人工呼吸再CPR，不要花时间"控水"。触电急救先断电再碰人。所有意外场景的通用原则：**先保证自身安全，再救人；先处理致命问题（无呼吸、大出血），再处理次要问题**。
