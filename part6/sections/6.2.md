# 6.2 心肺复苏（CPR）与AED——黄金四分钟，你是患者唯一的希望

> 心脏骤停后，每延迟1分钟进行CPR，存活率下降7%-10%。4分钟后大脑开始不可逆损伤，10分钟后几乎无生还可能。在专业急救人员到达之前，**在场者的CPR是患者活下来的唯一机会**。

## 一、识别心脏骤停——不要浪费时间找脉搏

### 1.1 三步判断（10秒内完成）

| 步骤 | 操作 | 判断 |
|------|------|------|
| **① 拍喊** | 双手拍双肩，大声喊"你还好吗？" | 无反应 → 进入下一步 |
| **② 看呼吸** | 观察胸部起伏5-10秒 | **无呼吸或仅有濒死喘息**（不规则、缓慢、张口样呼吸） |
| **③ 判断** | 无反应 + 无正常呼吸 | → **立即开始CPR + 让人拨打120 + 去取AED** |

> 🔴 **关键提示**：非专业人员**不要去摸脉搏**——摸不出、浪费时间、可能误判。"无反应+无正常呼吸"就足以启动CPR。濒死喘息（agonal breathing）不等于正常呼吸——看到不规则的、像鱼张嘴一样的喘息，也要按心脏骤停处理。

## 二、成人CPR标准流程——C-A-B

### 2.1 C：胸外按压（Compressions）

| 参数 | 标准 |
|------|------|
| **位置** | 胸骨中下段——**两乳头连线中点** |
| **手势** | 双手交叠，掌根接触胸骨，手指翘起不接触胸壁 |
| **深度** | **至少5cm，不超过6cm** |
| **频率** | **100-120次/分钟**（大约每秒2次） |
| **回弹** | 每次按压后必须让胸廓**完全回弹**（不要倚靠在胸壁上） |
| **中断** | 尽量减少中断，每次中断不超过10秒 |

**按压节奏辅助**：在脑海中播放以下歌曲的节拍——都是100-120BPM：
- 《Stayin' Alive》（Bee Gees）
- 《最炫民族风》
- 《小苹果》

### 2.2 A：开放气道（Airway）

每30次按压后，进行2次人工呼吸前：

| 操作 | 说明 |
|------|------|
| **仰头抬颏法** | 一手压前额，另一手的食指+中指抬起下巴（颈椎损伤者改用推颌法） |
| 检查口腔 | 如有可见异物用手指钩出 |

### 2.3 B：人工呼吸（Breathing）

| 操作 | 说明 |
|------|------|
| 捏住鼻子 | 用压前额的手捏紧鼻翼 |
| 口对口 | 施救者口完全包住患者口 |
| 吹气 | 缓慢吹气约1秒，看到胸廓抬起即可 |
| 连续2次 | 每次吹气后松开鼻子让气体呼出 |
| 比例 | **30次按压 : 2次吹气** |

> 🔑 如果不想做或不会做人工呼吸，可以只做**单纯胸外按压（Hands-Only CPR）**——有按压比什么都不做强得多。对于目击下的成人心脏骤停，前几分钟单纯按压的存活率与标准CPR相近。

### 2.4 完整循环

```
按压30次 → 吹气2次 → 按压30次 → 吹气2次 → ...（循环）
每5个循环（约2分钟）检查一次是否需要切换按压者
```

> ⚠️ 高质量按压极其耗费体力。如果有多人在场，**每2分钟轮换一次按压者**——疲劳会导致按压深度不足。

## 三、儿童CPR（1岁至青春期）

| 参数 | 与成人CPR的差异 |
|------|----------------|
| 按压深度 | 约**5cm**（胸廓前后径的1/3） |
| 手势 | 小儿童可用**单手掌根**；较大儿童同成人双手 |
| 按压:吹气 | 单人施救30:2；**双人施救15:2** |
| 启动时机 | 目击猝然倒地→先呼叫120再CPR；非目击（发现时已倒地）→**先CPR 2分钟再呼叫120** |

> 🔑 儿童心脏骤停多为**呼吸原因**（窒息、溺水），所以儿童CPR强调先做2分钟再求救——给氧是首要的。

## 四、婴儿CPR（<1岁）

| 参数 | 操作 |
|------|------|
| 按压位置 | **两乳头连线中点稍下方** |
| 按压手势 | **两根手指**（食指+中指）或双拇指环抱法（双人时） |
| 按压深度 | 约**4cm**（胸廓前后径的1/3） |
| 人工呼吸 | 施救者**口包住婴儿口鼻**同时吹气——只需看到胸部微微抬起 |
| 比例 | 单人30:2；双人15:2 |

> ⚠️ 婴儿头部不可过度后仰——气道柔软，过度后仰反而会堵塞气道。保持"嗅物位"（轻微仰头）即可。

## 五、AED（自动体外除颤器）——傻瓜式救命神器

### 5.1 什么是AED？

AED是一种便携式设备，能自动分析心律并判断是否需要电击除颤。它是为非专业人员设计的——**开机后有全程语音提示，你只需要听指令操作**。

### 5.2 AED使用步骤

| 步骤 | 操作 |
|------|------|
| **① 开机** | 打开AED盖子或按下电源键——自动开始语音提示 |
| **② 贴电极片** | 按照电极片上的图示贴在患者裸露的胸部：一片在右上胸（锁骨下方），一片在左下胸（腋前线） |
| **③ 分析** | AED提示"正在分析心律，不要触碰患者"——所有人离开患者 |
| **④ 除颤** | 如果需要电击，AED会提示"建议电击，请按下闪烁按钮"——确保所有人离开后再按 |
| **⑤ 继续CPR** | 电击后（或AED提示不需要电击），立即继续CPR——从按压开始 |

### 5.3 AED使用铁律

| 铁律 | 说明 |
|------|------|
| **听指令** | AED怎么说就怎么做——语音一步步引导 |
| **贴片前擦干** | 如果患者胸部有水/汗，快速擦干再贴电极片 |
| **避开膏药/药物贴片** | 电极片不要贴在膏药、起搏器等上面 |
| **取下金属饰品** | 项链等金属物取下（不要求完全脱净衣物） |
| **放电时全员离开** | 喊"离开！"确认无人接触患者后再放电 |

> 🔑 AED到了就**立刻用**——不要等做完几轮CPR再用。越早除颤，存活率越高。

## 六、特殊情况的CPR调整

### 6.1 溺水者

| 调整 | 说明 |
|------|------|
| 优先通气 | 先从**5次人工呼吸**开始，然后再30:2循环 |
| 原因 | 溺水是窒息性心脏骤停，体内严重缺氧 |

### 6.2 气道梗阻导致的心脏骤停

- 每次开放气道吹气前，**快速检查口腔**——看到异物立刻取出
- 如果能看见异物但取不出，继续CPR——按压产生的压力可能将异物推出

### 6.3 孕妇（孕20周以上）

- CPR体位：在右侧髋部下垫高，使子宫左倾
- AED可以使用——对胎儿安全
- 按压位置与成人相同

### 6.4 创伤性心脏骤停

- 如果怀疑脊柱损伤，用**推颌法**（不仰头）开放气道
- 大出血必须先控制（见6.3章）

## 七、什么时候可以停止CPR？

| 停止条件 | 说明 |
|---------|------|
| ✅ 患者恢复意识、正常呼吸 | 翻身侧卧（复苏体位），继续观察 |
| ✅ AED提示不需要除颤且患者恢复脉搏/呼吸 | 同上 |
| ✅ 专业急救人员到达接手 | 向他们汇报CPR时长和AED使用情况 |
| ✅ 施救者精疲力竭无法继续 | 如果有人接替，可以轮换但不要停 |
| ✅ 环境变得不安全 | 先保证自身安全 |

## 八、CPR常见顾虑解答

| 顾虑 | 解答 |
|------|------|
| "我怕按断肋骨" | 按断肋骨比死好。而且规范按压很少导致严重损伤。即使按断——反正不按也会死 |
| "我怕传染病" | 可以只做单纯胸外按压（不做人工呼吸）。身边有面罩/隔离膜更好 |
| "我不确定该不该做" | 记住：**宁可给不需要CPR的人做CPR，也不要不对需要CPR的人做**。对一个有脉搏的人做CPR通常只会让他不舒服，但对一个没脉搏的人不做CPR他会死 |
| "我会不会被告" | 中国《民法典》第184条规定：因自愿实施紧急救助行为造成受助人损害的，救助人不承担民事责任（"好人法"） |

## 九、本章小结

心脏骤停识别三步走：无反应→无正常呼吸→开始CPR。按压是核心：5-6cm深、100-120次/分、胸廓完全回弹、30:2（或单纯按压）。AED到了立刻用、听指令操作、放电时全员离开。儿童和婴儿在细节上有差异但原理相同。会做CPR不一定能救活每一个人，但不会做CPR就一定救不活。下一章将讨论另一个"分秒必争"的场景——严重出血的紧急控制。
