# 6.1 气道梗阻急救——海姆立克法，人人都该会的救命技能

> 气道完全梗阻后，人会在4-6分钟内因缺氧而脑死亡。急救车平均到达时间是8-12分钟。也就是说，当一个人在你面前噎住时，**能救他的只有你**。

## 一、识别气道梗阻——分秒必争的判断

### 1.1 部分梗阻 vs 完全梗阻

| 类型 | 表现 | 处理 |
|------|------|------|
| **部分梗阻** | 能咳嗽、能说话、能呼吸（可能有喘鸣音） | 鼓励**用力咳嗽**，不要拍背，不要干预 |
| **完全梗阻** | **不能说话、不能咳嗽、不能呼吸**；双手抓喉咙（窒息通用手势）；面色发紫 | 🔴 **立即海姆立克法** |

> 🔑 **一句话判断**：问他"你噎住了吗？"——如果能点头/摇头/出声，是部分梗阻，让他自己咳。如果**只能摇头、发不出任何声音、面色开始变紫**→立即海姆立克。

### 1.2 窒息通用手势

患者会用双手抓住自己的喉咙——这是窒息的国际通用求救信号。看到这个手势，不要犹豫，立即行动。

## 二、成人及1岁以上儿童——海姆立克腹部冲击法

### 2.1 操作步骤

| 步骤 | 操作 | 说明 |
|------|------|------|
| **① 站位** | 站在患者背后，双臂环抱其腰部 | 如果患者已倒地，见2.3 |
| **② 握拳** | 一手握拳，**拇指侧**抵住患者腹部中线位置——**肚脐上方两横指、胸骨剑突下方** | 位置过高会伤及肋骨/胸骨；过低伤不到膈肌 |
| **③ 冲击** | 另一手包住拳头，**快速、用力**向内上方冲击 | 方向是"内+上"，像要把人提起来 |
| **④ 重复** | 连续冲击5次为一组，检查异物是否排出 | 不要停，直到异物排出或患者失去意识 |

### 2.2 冲击的力度与方向

```
正确方向：↗（向内 + 向上）
错误方向：→（只向内）或 ↑（只向上）
```

每次冲击应该是**快速、有力、短促**的，利用腹内压骤然升高将膈肌上推，压缩肺部产生气流，像"人工咳嗽"一样把异物冲出。

### 2.3 如果患者倒地或体型过大

当患者已经失去意识倒地，或施救者无法环抱患者时：

1. 将患者**仰卧平放**在硬质地面上
2. 跨坐在患者大腿上（或跪在一侧）
3. 一只手掌根放在腹部（肚脐上两横指）
4. 另一只手叠放其上
5. **向前上方**快速推压5次
6. 检查口腔→看到异物用手指**钩出**（不要盲探）

> ⚠️ 意识丧失的患者→同时呼叫120，准备CPR（见6.2章）。

## 三、婴儿（<1岁）——拍背+压胸法（禁忌腹部冲击！）

婴儿的肝脏和肋骨尚未发育完全，**绝对禁止用海姆立克腹部冲击法**——会导致内脏破裂。

### 3.1 操作步骤

| 步骤 | 操作 |
|------|------|
| **① 体位** | 将婴儿**面朝下**放在你的前臂上，用手托住其头部和下颌（保持气道开放）。前臂支撑在你的大腿上，使婴儿头部**低于躯干** |
| **② 拍背** | 用另一只手掌根部，在婴儿**两肩胛骨之间**用力拍击**5次** |
| **③ 翻转** | 将婴儿翻转为**面朝上**，保持头部低于躯干。用两根手指（食指+中指）在婴儿**两乳头连线中点下方**按压**5次**——深度约4cm |
| **④ 循环** | 重复"5次拍背 + 5次压胸"，直到异物排出或婴儿失去意识 |

### 3.2 关键细节

- 全程保持婴儿头部低于躯干——利用重力辅助异物排出
- 不要用手指在婴儿嘴里**盲探**——可能将异物推得更深
- 只有**看到**异物时才用手指钩出
- 如果婴儿失去意识→立即开始婴儿CPR（见6.2章）并呼叫120

## 四、自救——当你一个人噎住时

### 4.1 方法一：用椅子自救

1. 找到一把有靠背的椅子（或其他边缘硬物：桌边、栏杆）
2. 将腹部（肚脐上方）对准椅背边缘
3. **用力向下压**，用身体重量产生冲击力
4. 重复直到异物排出

### 4.2 方法二：用拳头自救

1. 一手握拳放在肚脐上方
2. 另一手包住拳头
3. 向内上方**快速冲击**
4. 也可靠在墙上借力

> 🔴 **最重要的事**：如果旁边有人，即使说不了话，也要用**窒息手势**（双手抓喉咙）示意他们你是噎住了。如果独自一人，在还能行动的时候立刻去有人的地方或**拨打120**（即使说不出话，保持电话接通也能定位）。

## 五、特殊人群的调整

### 5.1 孕妇（孕晚期）和肥胖者

腹部冲击法可能无效或造成伤害。改用**胸部冲击法**：

| 步骤 | 操作 |
|------|------|
| ① 站位 | 同海姆立克，站在背后 |
| ② 手位 | 拳头放在**胸骨中段**（两乳头连线中点），不是腹部 |
| ③ 冲击 | 直接向后冲击（不是向内上） |
| ④ 循环 | 5次一组，直至异物排出 |

### 5.2 意识丧失的孕妇

- 仰卧位时应在**右侧髋部下垫高**，使子宫左倾，避免压迫下腔静脉
- 胸部按压位置同标准CPR

## 六、常见误区

| 错误做法 | 为什么错 |
|---------|---------|
| ❌ 拍背（对成人） | 对完全梗阻无效，甚至可能让异物卡得更深 |
| ❌ 用手指抠喉咙 | 盲探可能把异物推得更深，还可能被咬伤 |
| ❌ 倒吊起来抖 | 不仅无效，还可能造成颈椎损伤 |
| ❌ 给水喝"冲下去" | 完全梗阻时水根本下不去，只会呛入气道 |
| ❌ 对婴儿用海姆立克 | 腹部冲击会损伤婴儿肝脾 |

## 七、急救后的就医

异物排出后，即使患者感觉完全好了，也建议去医院检查：
- 腹部冲击可能导致内脏损伤（即使不疼）
- 异物可能在气道中造成擦伤或残留
- 如果冲击过程中有肋骨损伤的迹象（疼痛、按压痛）——拍X光片

## 八、本章小结

气道完全梗阻是分秒必争的急症——四分钟是黄金窗口。成人用海姆立克腹部冲击法（肚脐上两横指，向内上快速冲击），婴儿用拍背+压胸法（绝对禁用腹部冲击），孕妇和肥胖者改用胸部冲击。自救可以用椅子边缘或自己拳头。异物排出后仍建议去医院排查内脏损伤。下一章将讲解气道梗阻后最坏的情况——患者失去意识后如何进行心肺复苏。
