## 全书结构

- **第一篇**：家庭用药基础（药箱配置、用药原则、药品储存）
- **第二篇**：内科常见病症（呼吸、消化、发热、疼痛）
- **第三篇**：外科与皮肤问题（过敏、创伤、五官科）
- **第四篇**：特殊人群用药指南（儿童、老人、孕期哺乳期）
- **第五篇**：户外急救与实用附录（急症、蛇虫叮咬、药品清单）
- **第六篇**：急救技能（海姆立克、CPR、止血、意外急救）
