# 常见病症及治疗指南

> 家庭自我诊疗实用手册 —— 识别常见病症，科学安全用药

## 关于本书

本书面向普通家庭，系统梳理了日常生活中最常见的病症及其家庭处理方法。从感冒发烧，从到老人注意事项，从户外急救到家庭药箱配置，提供**实用、安全、易懂**的指导。

## 核心理念
    
- **能在家处理的不去医院** —— 减少不必要的就医负担
- **安全第一** —— 明确标注何时必须就医
- **因人而异** —— 老人、孕妇、儿童用药区分对待
- **有备无患** —— 家庭常备药 + 户外急救知识

## 适用人群

- 关注家庭健康的普通人
- 有老人、儿童需要照顾的家庭成员
- 户外运动爱好者
- 希望减少不必要就医的人群

## ⚠️ 重要声明

本书仅供参考，不能替代专业医疗诊断。如症状严重、持续不退或无法判断，请及时就医。

## 全书结构

- **第一篇**：家庭用药基础（药箱配置、用药原则、药品储存）
- **第二篇**：内科常见病症（呼吸、消化、发热、疼痛）
- **第三篇**：外科与皮肤问题（过敏、创伤、五官科）
- **第四篇**：特殊人群用药指南（儿童、老人、孕期哺乳期）
- **第五篇**：户外急救与实用附录（急症、蛇虫叮咬、药品清单）
- **第六篇**：急救技能（海姆立克、CPR、止血、意外急救）
